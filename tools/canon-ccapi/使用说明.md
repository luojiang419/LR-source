# CCAPI 激活工具

2026-10-22 已下载并解压 Windows 完整包，程序位置：

`G:\app\LR\tools\canon-ccapi\activation-win-v1.3.0e\CCAPI Activation Tool.exe`

同目录保留原包 `EDSDK.dll`、`IJPLMCOM.dll`、`ReadMe.txt`，不要混入其他版本或 64 位 EDSDK DLL。包名为 v1.3.0e，EXE 自报文件版本为 1.0.0.0，不能将包名视为已验证的 EXE 版本。

来源是 IOC Snapshot 厂商公开的 [Canon 相机支持页](https://iocsnapshot.com/compatible-cameras/canon-camera/)所链接的[下载包](https://iocsnapshot.com/CCAPI_Activation_Tool_Win_v1.3.0e.zip)，并非从佳能官网直接取得。ZIP CRC 检查通过，文件哈希与静态检查见 `技术文档/CanonR6m2接入点分析/ccapi-activation-acquisition.json`。EXE 和两份 DLL 均无 Authenticode 签名，尚无法独立认证为佳能原始发布文件；没有宣称认证通过或实机兼容通过。

本机 .NET Framework 4.8 满足 EXE 声明的 .NET Framework 4.5.2 依赖，三份程序均为 x86。配套 EDSDK 较旧（13.9.11.0），但已实际验证它能枚举本机 R6m2；激活工具现已显示成功提示。原包文件未更换，数字签名缺失的来源限制仍保留。

佳能[官方操作指南](https://downloads.canon.com/sdk/CameraControlAPI_OperationGuide_EN.pdf)描述的流程是：电脑联网，相机关机接 USB，开机，启动工具，Execute Activation，阅读通知并接受后继续；成功后退出，关闭相机并断开 USB，再开机检查 CCAPI 菜单。通知说明佳能会收集机型及可能的相机序列号、设备 ID 等信息。
