# SHIYING更新与安装

改编自 VoxCPM 独立更新事务与原生 SharedTheme。保留签名清单、断点续传、SHA-256、白名单、逐文件备份、journal、启动健康验证及回滚。安装器和更新器均为原生 .NET Framework 窗口，独立冻结事务环境，不依赖选片引擎或用户安装 Python。

`assets/photo-flow.svg` 是重新设计的照片筛选动画。构建时在 Chromium 中按 SVG 时间轴渲染透明帧，原生窗口循环播放；避免依赖 IE/SVG 插件或将完整浏览器捆入安装器。

签名私钥只存放于忽略的 `.update-private/signing-key`。不要删除或上传。客户端公钥首次发行后不得无迁移替换。

工作台启动后静默检查并下载新版，完整软件包通过长度及 SHA-256 校验后才提示“立即更新”。下载缓存位于资料目录 `maintenance/updates/downloads/<version>-<releaseId>/`，断点和已验证的完整包可跨启动复用；失败不打开更新器，可手动检查重试。用户点击“立即更新”后打开原生窗口，独立 worker 使用该缓存中的签名清单和软件包再次校验，无需重新下载；关闭未开始的更新窗口后可再次打开。页面缓存的常规后台刷新保持静默，不在检查更新旁显示进出频繁的状态文字。

更新包校验完成后，worker 登记绑定当前桌面/引擎实例的交接请求。前端轮询与原生检查共同触发保存评级和图片元数据；更新专用退出不走“询问关闭/最小化到托盘”。正常退出统一等待最多 8 秒；无响应、后台队列收尾过久或残留实例时，worker 自动结束该安装目录的桌面、引擎及后台子进程，再等待最多 5 秒确认退出。进程以完整安装路径识别并保留 Windows 句柄，避免 PID 复用；独立更新器及其分支受到保护，不按通用进程名杀进程。明确取消或保存失败中止更新；不响应的保存/退出允许超时强制终止，尚未完成的任务可能中断，应在更新前完成操作。worker 再次检查目标目录和端口释放后才建立替换事务；签名校验、逐文件备份、健康检查及回滚保持。手动安装器覆盖更新同样使用此规则，卸载仍要求正常关闭。

安装器以当前用户运行，优先选择 D、E 等空间充足且可写的固定分区；无合适分区时回退用户 Programs 目录。系统集成使用 HKCU 卸载注册、桌面和开始菜单快捷方式，独立卸载器先复制到用户临时目录再移除程序文件。安装标记保存资料路径与受管文件哈希，卸载保留资料、模型、未知或已修改文件。

安装目录内的 ADB 服务可能脱离主程序进程树独立运行。更新器按完整安装路径识别三种受支持位置的 adb.exe，经过句柄核验后纳入有界退出；不执行全局 `adb kill-server`，不处理外部 Android SDK、模拟器或其他安装目录中的同名服务。签名清单中的文件与现有大小及 SHA-256 一致时直接保留，不重复备份和替换；差异文件继续走原有事务和回滚。已使用旧更新器遇到 ADB 占用错误时，下载新版轻量或全量安装器并沿用原目录覆盖安装即可获得此修复。

首次安装和修复均允许选择非空目录，即使主程序缺失也可直接覆盖安装。仅替换签名清单内的程序文件，保留照片、设置和无关文件；覆盖前逐文件备份，安装失败自动回滚。安装目录及其父路径仍禁止链接，程序文件目标不能被目录或链接占用。

2026-10-21 覆盖安装修复验收：`python -X utf8 -m unittest discover -s 更新系统/tests -v` 的 36 项测试通过；重建 `dist/SHIYING 数字资产安装器.exe` 后，真实安装器在非空且缺少主程序的隔离目录安装成功，768 个程序文件哈希一致，覆盖前旧文件备份及照片／无关文件保留通过，工作台与引擎健康检查通过。证据为 `build/installer-overwrite/result.json`；本轮未请求模型或驱动安装、未注册测试应用，未发布远端安装器，正式版本与发布号保持不变。

构建顺序：`python -X utf8 更新系统/scripts/release.py prepare` → `python -X utf8 更新系统/scripts/build_tools.py` → `python -X utf8 选片助手/build_release.py --stage-only` → `python -X utf8 更新系统/scripts/release.py build --notes "更新说明"`。通过隔离验收后再用 `release.py publish --snapshot 完整快照目录` 发布。
