# 分屏拍摄演示

演示源码位于独立 worktree `D:/data/codex/tree/split-capture-demo/LR`，分支 `feat/split-capture-demo`。正式工作区、安装版及生产数据库均保持原状。

双击该目录下的 `启动分屏拍摄演示.cmd`，或运行：

```powershell
python -X utf8 选片助手/split_demo.py --source G:/app/LR --browser
```

演示地址为 `http://127.0.0.1:8792/`。第二个独立设备服务监听 `127.0.0.1:8793`；二者通过真实 Bearer API Key 请求读取目录、检索数据与传输 JPEG，不使用模拟图片响应。

## 操作

1. “视图 → 分屏拍摄”切换两区。演示默认开启，右侧沿用真实选片页，示例照片评级写入独立数据目录。
2. 左侧参考资源栏复用选片页的资源位置卡片与文件夹行样式。每个位置只显示当前层的目录，进入下级时替换列表，通过“返回上级”浏览父目录；不会层层缩进。远端只显示共享名称与相对目录，不显示盘符或绝对路径。
3. 选择目录后，在第二栏浏览真实缩略图；搜索范围为当前目录及子目录，自动使用 Everything，失败时回退到目录数据库并显示实际状态。
4. 缩略图右上角图钉、右键“设为参考”、大预览右上角图钉都可添加参考，支持同时保留多张。底部“参考图”面板展示全部已固定图片，点击缩略图切换，右上角“×”移除；面板可以折叠。重复添加同一资源不会产生重复项，固定后浏览其他素材不会替换当前参考。旧版单张参考自动迁移，集合、当前参考和参考栏折叠状态在刷新后保留。
5. 鼠标移入左侧预览或其面板后，可直接按 `← / →` 切换参考图，无需先点击；右侧照片保持不变。左右悬浮箭头也能切换，移出左侧后隐藏。鼠标位于右侧时保留原选片导航；编辑输入框或打开对话框时不抢占方向键。参考图在首尾停止，不循环。
6. 参考资源最左侧整条 16px 边条均可点击展开／收起目录，中央保留箭头提示。“目录”“素材”分别折叠参考双栏；“拍摄目录”“拍摄信息”分别折叠右侧面板。“沉浸对比”同时收起两侧模块与底部参考栏，再次点击恢复进入前的各模块状态。参考图支持滚轮缩放、放大后拖动和“适应”复位。
7. “设备与 API”或“设置 → 文件数据库与 API”可添加本机目录、创建命名 Key、分配读取目录、查看、复制与停用。调用其他设备时填写名称、IP + 端口及对方 Key，界面展示补齐后的地址，连接成功后目录出现在资源栏。

“加载图片”支持一次选择多张本机图片。通过文件选择器临时加载的图片只在当前页面有效；来自本机／API 资源库的参考图可以在刷新后恢复。

## 数据与验证

- 使用从 `G:/app/LR/build/local-model-validation/` 复制的真实样片，不使用原片作为写入目标；来源记录为 `build/split-capture-demo/sample-provenance.json`。
- 演示数据库、Key、样片、日志与截图均位于本 worktree 的 `build/split-capture-demo/`，已由 Git 忽略。磁盘上的 Key 使用当前 Windows 用户 DPAPI 加密；鉴权使用 SHA-256 哈希，远端不提供 Key 管理接口。
- 本轮只监听回环地址，不公开本机文件。跨实体设备的绑定、防火墙与运行部署留待方案确认后的正式集成；当前已经实测两套独立数据库之间的 HTTP 鉴权、目录和图片传输。
- 为使演示有界，本机参考库每个目录最多索引 20,000 张、每页 60 张；参考图支持 JPG、PNG、WebP、TIFF、BMP。生产百万库的后台索引、RAW 参考图等不在本轮演示范围。
- 没有连接真实相机或真实第二台设备；本轮不发布、不打安装包、不修改正式版本。

必要检查：`python -X utf8 -m unittest test_split_resources test_everything_discovery -q`（工作目录 `选片助手`）；服务启动后可运行 `python -X utf8 tools/verify_split_demo.py`。验证脚本会创建随后停用的测试 Key，不输出明文密钥。


## 汇总到主项目后的启动兼容

启动脚本使用当前项目路径。现有验证照片可用时沿用副本；缺失时生成带 GENERATED DEMO SAMPLE 字样的合成样片，来源写入 build/split-capture-demo/sample-provenance.json，不把它们作为实拍画质或识别准确率的验证。演示覆盖层在异步首屏就绪后加载；默认主程序继续使用正式分屏实现。
