# 末帧三主题布局演示

双击本目录 `index.html` 可离线查看；项目根目录也提供 `启动三主题布局演示.cmd`。

本轮为确认布局制作。评级与模拟状态仅保存在页面内存；主题使用独立的预览偏好键。演示不连接选片服务、真实监控、鼠标接收器或 LR，不修改原片和正式程序。

可体验：象牙白 / 星夜黑 / 醇白、单张 / 网格、搜索与筛选、评级、文件夹切换、专注模式、模拟现场跟随、拍摄进度筛选、资产选择与示例清单导出。右侧「选片规则」默认折叠，可展开查看控件。

照片使用项目原有演示样片。SKU 与任务状态为模拟数据，设备状态明确标注为未连接。

设计源文件为 `preview.template.html`，运行 `python -X utf8 build_preview.py` 重建独立页面，需要 Pillow；可选 `--inline <本次聊天的预览绝对路径>` 同时生成聊天预览片段。常规查看不需要 Python、Node 或联网。

颜色依据：`E:/APP/SHIYIN-AI/static/css/studio-unified.css`。图标为 SHIYIN 项目现有 Lucide v1.16.0，ISC 许可保留在 `lucide.js` 文件头。
