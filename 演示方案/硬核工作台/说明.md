# 最新页面 · 硬核布局演示

已确认方案已接入正式桌面，直接使用 `启动末帧.cmd` 测试。此入口保留为隔离预览，以当前 `演示方案/index.html` 和全部正式前端组件为唯一功能来源，不再注入旧候选脚本或重复移动组件。正式集成与验证见 [026-确认布局正式集成与实测](../../开发任务/026-确认布局正式集成与实测.md)。

双击项目根目录 `启动硬核工作台演示.cmd`，使用本机 Python 启动隔离预览，访问 `http://127.0.0.1:8795/`。旧8791硬核演示入口自动跳转至此，单独双击HTML不再提供离线业务副本。

- 硬核：MiniMax 中性深色、绿色反馈、三栏、中央胶片条、顶部页面导航。默认将现有「文件夹」和「现场监控」入口排在同一行；折叠目录、收起左栏、进入监控或拍摄进度时，监控入口返回顶部，保持可访问。
- 经典三主题：维持当前页面三栏结构，使用重新设计的暖象牙、柔雾深灰和瓷白材质；胶囊按钮、细腻投影、半透明磨砂面板覆盖侧栏、表单、弹窗与菜单。手机宽度纵向排列现有区块，避免裁切。主题弹窗中可往返切换，保留当前照片与评级。
- 全部功能入口来自当前页面：选片和拍摄进度两个页面，备案/归档/视觉解析/RAW补写仍在当前页面原组件内。没有独立资产管理页、现场记录标签、演示近邻照片组或模拟传入按钮。

「鼠标遥控」右侧新增「视图」入口：悬停展开六个原有显示开关，点击勾选显示，再点取消隐藏，折叠状态沿用原有记忆。隐藏顶部或进入专注预览时，视图入口保留在左上角以便恢复。方向键、空格和Esc可操作菜单；拍摄进度页暂不使用选片面板开关。

四种风格的「选片 / 拍摄进度」均位于顶部操作栏，「视图」入口之后；原页面导航栏承载选片筛选、搜索、视图、排序与预览控制，宽屏横排，窄屏换行并可横向滚动视图工具。进入拍摄进度时隐藏选片工具；隐藏顶栏时页面导航自动回到工具栏位置，仍能切换页面和恢复顶部。

样片复制到 `build/hardcore-workbench/samples`，评级仅保存至 `build/hardcore-workbench/data`，独立端口也隔离浏览器主题与布局偏好。演示服务接受隔离评级会话保存与只读选片清单预览；设备、LR、模型配置、导入和元数据写入操作会返回演示提示。这些限制只属于隔离演示，正式桌面继续使用完整后台功能。
