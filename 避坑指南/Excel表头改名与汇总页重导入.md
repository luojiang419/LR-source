# Excel 表头改名与汇总页重导入

## 表现与根因

直接改显示列名后，按“款号”“拍摄状态”等文字查找业务列的导入器会失去定位依据；直接把派生汇总表当原表再次导入，也会重复计数。同一工作簿还可能经过插入图片列、备注移到末尾，原来的列号不再等于导出位置。

## 解决

- 业务键与显示名称分开，原导入件只读。改名和封面偏好属于项目 metadata，跟随已有备份。
- 先完成状态/图片列插入与备注移列，再按实际位置应用表头。Excel Table 的列描述及结构化引用一起更新，公式中的字符串常量不替换。
- 在工作簿 XML 映射中保存规范列名、显示名和单元格位置，并通过 customXml 关系关联。重导入在内存恢复规范列供识别，显示名仍保留；派生汇总页按映射跳过，重复导出复用该页。
- 输出先在临时文件完成全部处理，成功后替换；失败保留旧输出并回滚本次偏好。
- XML 声明使用标准 `utf-8`；`utf8` 声明配合中文属性会使部分 XML 读取器直接报 invalid token。

## 验证

`test_sku_presentation` 覆盖改名重导入、备注位置、汇总不重复、像素对应、元数据备份与导出失败回滚、结构化引用及字符串保护。2026-10-24 最终相关 67 项回归与真实冻结引擎导出/重导入通过，证据见任务 093 和 `build/shooting-presentation/`。
