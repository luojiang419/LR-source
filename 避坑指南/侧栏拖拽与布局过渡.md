# 侧栏拖拽与布局过渡

## 表现与根因

工作台用 `grid-template-columns` 过渡折叠面板时，连续拖拽调宽也会触发该过渡，面板宽度落后于鼠标。仅观察整个 grid 容器无法发现列宽变化，因为容器总宽没有改变；分隔线可能停在动画前的位置。窗口突然变窄时，尚未重新定位的绝对定位入口也可能暂时撑出横向滚动。

## 处理

- 拖拽期间对布局设置 `transition:none`，指针更新用 `requestAnimationFrame` 合并；释放后保存偏好并恢复普通折叠动效。
- 同时用 `ResizeObserver` 观察两侧面板，按实际边界定位分隔线。入口位置限制在容器内，窄屏用 CSS 立即隐藏，再由脚本同步可访问状态。
- 正常动画过程中读取宽度可能得到小数中间值；刷新恢复等验收应等布局稳定，同时单独验证鼠标按下时的即时宽度，不能只在减少动态效果模式下测试。
- 缩略图行高随栏宽变化后，虚拟列表必须使用真实高度前缀偏移；继续使用固定行高会导致末张定位和滚动留白错误。

## 验证

`test_sidebar_resize_browser.py` 验证四主题双侧拖拽、正常动效下即时变化、窄屏、刷新、取消、恢复默认和长列表；`test_workbench_integration.py` 验证完整源码/发行引擎的响应式布局与评级保持。记录见开发任务 027，截图在忽略目录 `build/sidebar-resize`。
