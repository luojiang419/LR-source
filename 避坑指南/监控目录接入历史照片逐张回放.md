# 监控目录接入时历史照片逐张回放

- 表现：相机模式恢复或添加有照片的监控目录后，画面随历史入库批次一路切到末张。
- 根因：历史枚举与真实传入共用接收通知和正序跟随编号；每批24张入库都推进last_photo_id，前端又以数量变化反复跟随。
- 解决：首次完整快照中的历史末张为0序号，其它历史为负序号；真正新图保持正序号。只对初始末张发布一次直通预览并优先入库，其它历史后台补齐。前端在会话/监控generation/目标ID变化时跟随，历史数量变化不切图。
- 顺序保护：末张优先入库须预留历史原位置，并让后来新图排在预留范围之后；已有记录位置保持。回填期间刷新当前有界目录页，完成后继续增量，避免缺拍摄时间的图片因入库先后改变导航和SKU区间顺序。
- 验证：test_watch_history.py覆盖73张首批24张即显示末张、整段回填保持画面、真实新图优先、快照前可信通知、重启与关闭跟随；测试逐项核对最终原顺序。详见开发任务215。
