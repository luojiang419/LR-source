# 归档刷新空白与预览连接阻塞

- 表现：右键刷新后目录树空白，界面误报尚未添加；数据库 roots 记录仍存在、removed=0，单独访问归档接口能返回根目录。
- 根因：只读 API 无谓等待完整会话和写入令牌；目录树又通过 Promise.all 等待素材、统计和参考进度全部成功。刷新时拍摄页图片及邻图预取还会竞争有限的同源 HTTP 连接，使问题在慢 NAS 上更明显。
- 解决：GET 直接读取、POST 继续校验凭证；目录结果独立显示，其他数据失败保留目录并明确提示；页面初始化先让脚本完成，隐藏拍摄页取消图片及预取，返回时恢复，后台解码队列保持持久化。
- 验证：连续空白右键+刷新、慢参考接口、会话/列表/统计失败、数据库重开和令牌写入；使用实际冻结引擎无资源替换验证，目录保留、移出请求为 0、源照片哈希不变。见任务 107 和 `test_archive_refresh_browser.py`。
- 排查时先确认数据库路径及 removed 状态，避免把界面加载失败误认为数据被删除；不要以禁用右键刷新、重建库或清空缓存代替修复。
