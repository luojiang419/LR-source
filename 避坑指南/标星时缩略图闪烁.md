# 标星时缩略图闪烁

## 表现与根因

选片页面标星后，左侧缩略图短暂闪烁。`workbench-layout.js` 的渲染签名包含星级、选中照片和 SKU；签名变化时通过 `innerHTML` 重建整段虚拟列表，导致原图片节点被替换，已解码图片和高亮动画重新创建。

## 处理方式

- 按照片 ID 复用可见按钮与图片，仅修改星级、SKU、选中状态及布局。
- 图片地址确实变化时才设置 `src`；滚动时只移除离开预取范围的节点，保留重叠部分。
- 切换会话时清空旧节点；签名包含备案选择状态及文件名，避免跳过必要更新。

## 验证（2026-10-23）

- Browser 使用 48 张隔离样本检查连续标星、撤销、清零、遥控评级、列表底部标星、1024px 窗口及非监控选片；标星时图片节点保持、图片加载和移除均为 0，滚动位置保持。
- 相邻切图复用原图片；切图仍按原规则定位选中项，新增预取图片可以正常加载。切换目录正确清除旧图。
- 安装目录资源复测通过，另确认选中图片的高亮动画实例不变，页面错误日志为空；JS 语法和 Git diff 空白检查通过。
- 同步五处受管网页资源及对应清单，保留版本和资料路径。现场运行窗口需正常重开后加载更新。
