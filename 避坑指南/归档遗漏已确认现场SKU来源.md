# 归档遗漏已确认现场SKU来源

表现：资产库已有款号，归档却提示“来源图片尚无确认SKU”。真实XSY_2915.JPG在目录索引中sku=LC7832746-P2909、source=shooting，当前文件没有内嵌SKU且locations未建关联。

根因：新归档快照读取只识别manual/embedded，遗漏现场已入库的shooting归属。已有目录索引SKU并不等于每张JPG当前都已内嵌，不能只凭磁盘字段决定是否备案。

解决：使用确认来源白名单（manual/embedded/shooting/ocr_folder/folder_default），继续拒绝path_rule/视觉候选；合并实际XMP侧车业务字段，保留原图相机身份读取；确认执行前重查数据库SKU，变更则阻断移动。不能把文件内容哈希用于RAW/JPG跨格式关联。

验证：36项归档/路径/恢复/身份/整理专项+1项新增侧车测试，共37项通过。真实4217来源全部SKU/快门身份读取成功；报错样本最终JPG/CR3与现场指纹均一致。全量最终JPG另查出4个快门无来源/持久记录，应单独请求确认；不要为追求全通过按同名/相邻照片猜款或跳过仍存在的大档。


补充：现场数据库可能已确认带-P等后缀的子款号，而旧JPG内嵌基础SKU尚未回写。读取顺序必须与执行前校验一致：已登记资产归属 → 非embedded的确认数据库归属 → 当前内嵌字段 → embedded索引回退。只修补“来源白名单”但仍让旧内嵌优先，会在执行前再次报归属变化。真实XSY_2298验证LC7832817旧值正确采用LC7832817-P905确认值，原件保持。

用户确认未联机入库照片不选用后：完整相机指纹无现场记录且自身也无SKU/AssetId才可按明确开启的规则排除，JPG/RAW按同一身份同时处理。保留原件、排除明细单列、不计选用分母；指纹缺失、既有SKU/资产归属或同身份业务冲突继续阻断。此规则已按用户最新授权更新，不能与“后期删除”混为一谈。
