# Lightroom 照片已导入，桥接却匹配为 0

表现：工作台握手和心跳正常，LR 显示“没有匹配的 LR 照片”，只提供映射目录和退出。界面中确实存在该日期文件夹。

本次根因：验证选了源文件夹的 `XSY_0927`，但它没有导入 LR。源目录共 1947 个拍摄编号，而 LR 对应日期目录只有 1701 张。另有映射盘与 UNC 路径表达差异，不能仅依据截图中的盘符推断全部原因。

解决：桥接在零匹配时批量读取 `getAllPhotos` 的 `path` 元数据，回传实际目录、照片数量和样本路径，不渲染 RAW；在同名日期目录和完整相对路径上查找唯一候选。多副本时手动映射，不能猜。验证应选目录索引证实存在的文件。

验证：改用诊断中出现的 `XSY_0929.CR3`，实际 LR 回传 `matched=1, changed=1, missing=0, conflicts=0`；其配对 JPG 非独立 LR 记录，`companions=1`。测试替身覆盖盘符/UNC、同日期跨盘匹配、不误用其他日期及评级保护。连接失败还需先确认服务正在运行，插件新版支持服务恢复后后台重连。
