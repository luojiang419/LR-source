# 内置 OCR 预加载与进度锁

开启内置模型后只保存配置，会把 llama.cpp 的启动时间留到第一次标星；若状态查询也取得整段推理使用的锁，加载期间连等待提示都无法更新。

预加载使用后台线程，开关请求立即返回。推理锁继续保护模型进程的生命周期，独立状态锁只维护阶段、起始时间和实际可测进度，查询不能取得推理锁。重复开启共用加载，关闭时标记请求代次取消，加载完成前再次检查代次，避免过期请求重新拉起模型。

组件复制/下载可使用实际 done/total，但需标明“当前文件准备进度”；健康检查只提供就绪信号时，不得把等待时间换算成假百分比。此阶段使用不定进度条与等待时长，真正就绪后再进入 OCR。任务进度同时绑定任务类型、job ID 和 run_token，防止撤星重标后的旧请求串入新任务。

验证包含：人为阻塞组件准备时，开关仍立即返回且快照可读取 42/100；预加载取消及去重；实际本机 GLM-OCR 在标星前加载就绪，标星后正确识别隔离标签，加载起始时间保持，证明没有重复加载。
