# 末帧选片

文件夹自动监控与无线鼠标遥控标星已接入正式工作台，使用方法见下方专节。另有 ESP32-S3 方案与独立流程模拟：双击 `启动硬件选片演示.cmd`；完整设计见 [软硬件演示方案](演示方案/硬件按钮选片/软硬件演示方案.md)。ESP32 固件与设备网关尚未开发，独立演示不连接生产数据。

Windows 本地选片程序，使用 LR 风格工作台浏览照片、按时间规则分组、保存人工评级，并通过 Lightroom Classic SDK 桥接同步星级。

**启动与关闭**：桌面版点击窗口关闭按钮，默认询问“最小化到托盘”或“退出程序”；开启“不再询问”后记住所选行为。可在“设置 → 启动与关闭”改为每次询问、最小化到托盘或退出程序。隐藏到托盘后后台任务继续运行，单击托盘图标或菜单“打开末帧选片”恢复窗口，菜单“退出程序”保存后退出，仍有后台任务时会提示确认。开机启动可选“不启动”“自动启动并显示窗口”“自动启动并静默到托盘”，对当前 Windows 用户生效；默认不启动，静默模式不弹出窗口，手动打开始终恢复窗口。

选片页中央预览默认右下角显示半透明直方图，宽度接近五颗星控件，高度约 108 像素。在“设置 → 预览显示”可调整直方图位置（四角或隐藏）和透明度（0%–100%），立即生效并自动保存；0% 保持原半透明外观，100% 完全透明。浮动控件设置采用双栏，窄窗口恢复单栏；标星、缩放、解析提示与直方图选择同一角落时按实际高度自动分排并对齐边缘，避免重叠。随当前照片显示 RGB 与明度分布，鼠标可穿透面板继续操作照片。统计取自显示预览的缩小采样，面板标注“预览 RGB”；无照片时隐藏，读取失败时提示预览不可用。

## 分屏拍摄与局域网参考库

在「视图 → 分屏拍摄」开启左右对照。左侧是参考资源和参考大图，右侧沿用当前选片、目录监控与评级。参考资源栏采用位置卡片及单层目录列表；点击进入子目录，点击上方路径返回。最左侧整条边栏都能展开／折叠。左右模块可分别收起，也可点击「沉浸对比」并恢复。

**归档与分屏共用媒体数据库**：从“资产归档”添加、刷新或移除的根目录会同步成为分屏参考资源；两处共用 `asset_catalog.sqlite3`、路径倒排索引、增量变化通知和预览缓存，不再为同一批素材创建第二份目录 SQLite 数据库。原有分屏目录会在启动时接入该归档索引。检测到本机 Everything 后，先提交最多 2048 条已索引媒体候选以便立即浏览和搜索，后台仍会完成自身的全量流式快照，不能把 Everything 的局部返回误判为全量完成。归档页与分屏资源栏均显示相同的后台进度语义：已扫描文件数、目录估算百分比和完成状态。

**专业媒体自动索引**：归档可直接收录 JPG/PNG/WebP、RAW（含 DNG）、TIFF、Adobe PSD/PSB/AI/EPS/INDD/PDF，以及 MOV/MP4/MXF/MKV/AVI/MTS/M2TS/R3D/BRAW 等视频或设计源文件。首次扫描只记录路径、文件属性和格式，索引线程不等待图片解码或视频探测；每批入库后立即通知独立后台预览队列，已提交批次即可检索。按文件名、路径或 SKU 搜索时使用持久倒排索引和游标分页。发行包自带 FFmpeg／ffprobe，添加归档后自动生成全部子目录的视频封面，并在独立后台资料队列中读取容器、编码、时长和尺寸。

**图片资料自动入库与搜索**：新添加和已有归档素材自动后台提取 EXIF、XMP 和视频资料，进度显示在归档位置概览中；重启接续任务，未变化的资料直接复用。双击素材只查询数据库，先显示已知字段，后台完成后自动补齐，无需等待原图或视频探测。详情展示拍摄参数、标题、描述、关键词、颜色、镜头及可展开的全部已读取标签；原片离线时仍能查看已入库资料。原文件或 XMP 的变化通知会重新排队，读取失败显示原因并提供“重新读取资料”。归档搜索可按实际入库文字查找，例如相机、镜头、日期、`ISO 400`、`f/2.8`、`1/125`、关键词或视频编码，中文及引号、百分号等按字面匹配；文件夹过滤和分页沿用相同范围。没有写入文件的画面内容需要先由用户填写标题/描述/关键词，或由现有识别流程生成资料；本功能不自动调用收费模型或凭空生成画面标签。元数据编辑继续自动保存并保留版本冲突校验。

**视频封面**：在“设置 → 预览显示 → 视频封面”选择帧序号，默认第 3 帧，从 1 开始计数，可设 1–1000；视频不足所选帧数时使用最后可解码帧。保存后重新打开素材列表更新封面，重启保持。归档与分屏使用同一设置，帧号参与缓存标识，修改后不会复用旧封面。封面在添加归档后自动并行提取并复用图片缓存，修改帧号后自动补齐全部归档视频。实际支持范围由 FFmpeg 解码器决定，已验证 H.264、HEVC、ProRes、DNxHR（含 MXF）；BRAW 等专有 RAW 视频不保证可解码，保留索引并明确提示失败。开发环境运行 `python -X utf8 选片助手/setup_ffmpeg.py` 部署固定版本；常规开发依赖安装也会部署，运行时及许可证随引擎打包。

**视频播放与空格预览**：资产归档双击视频进入全屏播放器并自动播放，右侧显示时长、尺寸、容器、编码、帧率、音频资料及已有拍摄标签。空格播放／暂停，左右键前后定位 5 秒；拖动下方进度条可跳到尚未缓冲的位置，暂停时拖动仍保持暂停。播放结束后按空格从头重播，静音按钮可开关声音，Esc 或“关闭”返回列表。上一项／下一项按钮可在图片和视频间切换；图片仍支持原有缩放和方向键切换。归档或 SKU 图片列表选中素材后按空格也能快速全屏预览，图片预览中再按空格可关闭；文本输入时空格保持正常输入。视频按当前播放位置实时解码为最高 1080p／30fps 的兼容预览，保留声音并转为双声道，不创建完整转码副本、不改动原素材。切换、定位和关闭会停止旧解码进程；专业编码以附带 FFmpeg 的实际支持为准，无法解码时显示原因。

**全目录预览准备**：添加归档位置后自动处理全部子目录，无需逐个进入文件夹触发。队列先完成所有已入队素材的 420px 缩略图，再补齐 4096px 清晰预览，避免早期大图编码占满工作线程；RAW 优先提取内嵌小图。右侧进度显示缩略图、清晰预览和失败数量，后台处理期间可继续搜索和浏览；重启自动接续，已有缓存直接复用。归档预先建立 420 和 4096 尺寸，原片保持只读。

**元数据写入空间策略**：内嵌元数据使用 ExifTool 标准输入/输出在内存中生成和校验结果，再通过同一受控句柄核对 SHA-256 并直接写回原文件。已移除整图临时编辑、跨卷暂存和原子替换机制，不创建 `.framekeep-write-*`、`.framekeep-staging/`、`metadata-staging/`、`.framekeep-recovery-*` 或 `original.bin`。普通写入异常尝试从内存恢复原内容；强制结束进程或断电时不再具备原子替换保障。磁盘只保留小型参数文本、字段历史及标准 XMP 侧车。XMP 伴随写入、小型元数据历史和失败原因记录保持。本次升级首次运行后，在后台清理一遍已配置监控、资产归档目录中的旧版 `.framekeep-recovery-32位十六进制` 文件夹，完成后持久保存执行标记；以后重启不再扫描，也不定时巡检。按用户指定策略，不要求原照片存在或恢复信息可验证，旧目录及其中内容直接删除；链接只移除链接本身。普通照片、普通 `.bin`、当前写入临时文件和软件资料/缓存不在清理范围，结果记录到软件资料目录的 `legacy-recovery-cleanup.json`。

左侧主预览区支持「网格／大图」切换。提交搜索后以网格显示当前页结果；单击选择，双击缩略图或按回车进入大图，按 Esc 返回网格。网格内普通滚轮上下滚动浏览，按住 Ctrl＋滚轮或使用上方滑杆调整缩略图显示比例，范围 10%–400%，比例和视图在本机记忆；滚轮缩放不重新搜索。缩略图宽度足够时显示完整文件名，放不下时自动隐藏，放大后恢复；悬停始终可查看完整名称。网格每页仍为 60 张，可使用上方翻页按钮。网格按图片所在文件夹分组，文件夹名称显示在分割线左侧，悬停可查看来源及相对路径。大图普通滚轮前后切图，Ctrl＋滚轮缩放，放大后可拖拽；工具栏提供平滑、线性、渐入、渐出、关闭叠化的曲线选项并在本机记忆，新图片加载完成后叠化切换，系统减少动画时直接切换，网格模式只加载缩略图，进入大图后才请求大预览。窄窗口中参考资源、参考预览与拍摄工作区上下排列，避免互相遮挡。

点击参考缩略图右上角图钉、右键「设为参考」或大图图钉，加入多张参考并自动展开底部参考区；底部面板支持折叠和移除，点击其中图片可直接大图浏览。左侧网格使用左右方向键选择结果，大图模式切换当前搜索结果或底部参考集合；移到右侧后继续切换拍摄照片。参考集合、当前位置与底部面板折叠状态保存在资料目录，重启恢复。「加载图片」用于本次窗口的临时本机参考；需要重启保留时，通过参考资源栏添加该图片所在目录。

本机参考图片的右键菜单提供「打开所在路径」，打开资源管理器并选中原文件；API 参考不显示右键菜单，直接读取资料机传回的结果。接收端将 API 搜索结果和参考预览保存为当前拍摄任务的临时副本，重复浏览优先复用本地缓存。底部参考区右侧「清理参考图」仅移除当前选中项，并清理该图片的临时副本；「×」和取消图钉同样触发清理。切换照片会话或拍摄文档项目时自动清空参考集合及临时缓存，刷新同一任务、切换同一项目的工作表保留。清理只处理已登记的临时副本，不删除原照片或共用的持久预览缓存。

在「设置 → 文件数据库与 API」或参考资源栏点击「＋」，通过「选择分区 / 文件夹」打开系统选择窗口，可一次多选、继续追加，在列表中修改显示名称或移除待添加项，无需手填路径。网络路径也可在折叠的手动输入区逐行加入。添加后先检查 Everything 已有索引，已覆盖的位置立即就绪，直接搜索，不重新遍历整棵网络目录；未覆盖或不可用时后台建立目录索引。UNC 与本机映射盘自动转换，RAW/JPG 配对及预览沿用正式缓存。每个位置提供独立的显示／隐藏滑动开关，重启记忆；隐藏收起本机资源栏入口并排除本机全部目录搜索，保留缓存、固定参考图和共享授权。「刷新索引」重新检查覆盖或更新目录索引；「移除」撤销资源位置与其授权，不删除原文件。

参考资源搜索在输入完毕后点击「搜索」或按回车才查询，输入、修改和清空文字均不自动请求；本机与 API 设备行为一致。翻页沿用上次提交的搜索条件，输入框中的新文字需再次提交才生效；清空后点击「搜索」恢复当前目录列表，切换目录则自动清空搜索。后台索引进度更新不会重复提交关键词搜索，避免产生重复查询与图片传输。

搜索范围默认“全部已添加目录”，可切换“当前目录及子目录”；范围选择在本机记忆，修改后再次点击搜索才生效，翻页沿用已提交范围。全局结果保留各自设备、目录与预览来源，重叠的本机目录不重复列出同一文件。Everything 已覆盖的位置直接取文件名/路径匹配及索引属性，只缓存命中资料，图片按需加载；OCR、SKU 入库时间等业务数据仍由末帧保存。设计与 Flow 本机对照见 [Everything 搜索接入](技术文档/Everything搜索接入与Flow对照.md)。

**无需 Everything 的本机快速索引**：本机完整索引建好后优先直接查询，搜索不再探测原图或遍历网络目录。无完整快照且 Everything 不可用时自动建库，单次批量读取文件名和属性，每批入库后即可搜索，不解码图片、不全库生成缩略图。新增、删除、改名由后台通知更新；重启先复用已有快照，再后台对账，离线仍可搜索已知记录。仅在实际预览时读取照片。首次 NAS 完整建库仍受网络与目录数量约束；初建显示已索引数量，后续按历史数量显示估计百分比，结束为 100%。设计与性能边界见 [原生快速索引](技术文档/原生快速索引与Everything机制对照.md)。

**索引调用开关与存储迁移**：在「设置 → 文件数据库与 API」切换「调用 Everything 数据库」，关闭后立即使用本机快速索引，并自动补建尚未完整索引的位置；开关重启保留，不改变 Everything 自身设置。同页的「文件索引数据库存储」显示当前路径，可选择高速硬盘上的独立空目录并点击「迁移数据库」。程序在所选目录内创建专用子目录，暂停索引读写，复制 SQLite 数据库和倒排索引，校验成功后切换；显示迁移进度并保留原数据库。迁移失败继续使用原位置，失败产生的副本保留在目标目录以便检查，重试请选择另一空目录。重启沿用新位置；外置盘离线时提示重新连接后重启，不静默创建空库。此项移动参考文件索引，不移动原图、SKU / 解析业务资料或 Everything 自己的数据库；预览缓存通过原有「预览与缓存」迁移。SSD 可改善索引读写，实际响应仍取决于数据规模、查询条件及缓存。

参考主预览上方、参考资源栏及设置的位置列表在后台索引时显示进度条、百分比与已扫描文件数，收起资源栏后主预览进度仍可见。首次扫描按已完成／已发现目录显示“约”百分比，发现更多目录后会调整；有历史文件总数时按文件数估算，完成后显示 100%。目录估算不代表已知全部文件总量，悬停可查看详细目录与文件数量；不为计算进度额外遍历目录。首次索引边发现边入库，目录树在进度刷新时保留展开状态、滚动位置与键盘焦点。

其他电脑也安装本应用后，在资料所在电脑启用「允许局域网设备调用本机数据库」，默认端口 `8770`，创建命名 API Key 并勾选可读目录。Key 支持重新分配目录、查看、复制和停用，使用当前 Windows 用户加密保存。在调用电脑填写对方局域网 `IP:端口` 和 Key，程序自动补齐 `http://` 与 `/api/library/v1`；连接成功后，对方的目录出现在左侧参考资源栏，显示共享名称，不显示远端盘符。共享默认关闭；开启后只提供鉴权的目录、列表与预览读取接口。若另一台设备无法连接，检查双方网络和资料电脑的 Windows 防火墙是否允许该共享端口。

## 安装与卸载

新电脑运行约 12.6 MB 的“末帧选片安装器.exe”。安装器从魔搭校验下载软件，再在安装阶段补齐 GLM-OCR 模型、CPU/CUDA 推理运行时、VC++ 运行 DLL 及 WebView2，支持断点续传，不需要预装 Python 或 Node.js。安装器本身不包含模型和推理运行时。当前默认仅启用 OCR，多模态作为后续开发预留，跳过约 5.54 GB 的 Qwen 权重；OCR 权重与压缩推理运行时合计约 2.96 GB，其余界面依赖按需准备。全新用户默认使用内置 OCR，已有用户的照片、评级及 API 选用保留。安装后可从桌面或开始菜单启动，也可在 Windows“已安装的应用”中卸载。

软件文件采用当前用户安装。新电脑缺少鼠标输入驱动时，官方驱动安装会请求 Windows 管理员授权，首次安装可能需要重新插接接收器或重启电脑；程序不会自动重启或关闭系统安全功能。已有驱动不会反复安装。

已安装用户开启“使用内置模型”后，点击现场 OCR、SKU 识别、解析页 OCR 或模型测试按钮，软件会自动检查并补齐 OCR 所需组件，显示准备进度后继续操作。内置多模态卡片和已有 Qwen 文件继续保留，显示预留状态，当前不选用、不自动绑定或启动，不因旧排队任务下载 Qwen。外部 API 配置继续保留。网络中断保留下载分片，可在进度卡片重试，补齐后重新点击原识别按钮；无需运行部署脚本。后台自动 OCR 同样具备组件准备与进度反馈。模型存放于当前资料目录的 `components/`，卸载保留。

**全自动 OCR 模式**在选片右侧栏或“设置 → AI 与模型”开启，两处开关同步，**无需导入 Excel 文档**。打开照片目录后即可启用；软件使用现场记录保存已有和后续照片的 OCR 全文及候选，RAW/JPG 配对按一个拍摄资产处理，不要求二星。点击正确的推荐款号即确认并写入，二星款末标签处理完整拍摄区间。没有选用模型时开关仍可开启，队列明确显示等待模型。需要与计划对账时，仍可在右栏“导入表格”选择 `.xlsx`，沿用同名工作表或第一个有效工作表并绑定当前目录。既有文档匹配、候选复核和拍摄记录保留。关闭或切换文档／工作表会停止未提交的自动任务；设置与已完成记录重启保留，已完成图片不因刷新重复识别。照片星级保持，原二星遥控和手动 OCR 继续使用。

选片右栏“当前拍摄”和拍摄进度页增加 **公共** 分类，集中列出出现在多个工作表中的款号，按规范化款号去重，并逐表显示拍摄状态。同一工作表中的重复行不算公共，各表进度独立；全部所属工作表都已拍摄才计为公共已完成。查看公共分类不会改变 OCR 的当前工作表，点击所属工作表按钮才切换到该表。导出仍保留原工作表和原行。

新装默认依次检查 `D:\Program Files\Framekeep`、E 至 Z 的对应路径，选择固定磁盘中空间充足且可写的位置。没有合适的非 C 分区时，使用 `%LOCALAPPDATA%\Programs\Framekeep`。已安装的软件优先沿用原位置，也可手动选择其他可写目录；安装前会同时检查安装分区和临时分区的空间。

新安装和便携版的资产库、评级、设置、模型、索引及预览统一保存在 `<安装目录>\data`。安装目录必须对当前用户可写；不可写时明确报错，不静默回退 C 盘。升级、修复或改装到另一目录时，停机后核验迁移旧 `.framekeep` 或登记资料，SQLite backup 包括 WAL；源目录保留，不覆盖已有非空 data，不创建空库替代旧评级。开发启动器显式指定的资料目录兼容。卸载只移除受管程序，保留 data。

卸载前请保存并正常关闭程序。卸载会移除登记的程序文件、应用注册、桌面和开始菜单入口；照片、评级、设置、模型和未知文件保留，修改过的程序文件也会保留。重新安装可继续使用原资料。便携版仍可直接运行原目录中的 EXE，沿用原有资料定位。

## 启动

双击 `启动末帧.cmd` 或 `dist/末帧选片/末帧选片.exe`，打开独立 Windows 桌面窗口，不启动外部浏览器。桌面主程序使用 **Tauri 2 + Rust + 系统 WebView2**；无需安装 Python、Node.js 或完整浏览器。发行时须保留整个同名目录（含 `engine/` 和 `runtime/`），不要只拷贝 exe。首次目标电脑须具备微软 Edge WebView2 Runtime。

重复启动会聚焦已有窗口；关闭窗口前保存评级，并结束本次桌面程序启动的选片引擎。仍有索引或待确认 LR 同步时会提示是否退出。桌面窗口异常结束时，引擎也会自动退出。

「浏览」使用 Windows 原生文件夹选择器，支持多选。选片右侧栏底部固定显示加大的「发送到 LR」按钮，上方设置独立滚动；选片结果通过该按钮同步，清单由后台生成和传递，界面隐藏手动下载入口。后台仅监听本机回环地址供桌面窗口和 LR 桥接使用，正常选片不需要访问网页。

在左栏「文件夹」标题旁点击 **＋** 或「＋ 添加文件夹」，粘贴本机、映射盘或 UNC 路径，也可使用「浏览」。每行一个路径，可一次添加多个文件夹，默认包含子文件夹。索引在后台排队进行，左栏显示阶段、进度、当前文件及失败原因，可停止或重试，不挡住当前选片。索引完成后点击左栏文件夹名称进入。

每个文件夹都是独立标星任务，分别保存人工评级、保留偏好、分组间隔、筛选、浏览位置。切换前自动保存，已添加文件夹在页面内切换，左栏列表持续显示；加载时保留原照片，失败时停留原目录，不重复索引；刷新或重启后仍能在左栏找到。添加索引不会自动切走正在处理的目录。批量添加上限为每次 50 个；任务队列只在本次服务运行期间保留，服务重启后尚未完成的目录需重新添加，已完成任务不受影响。

选片页最左侧整条边条均可点击展开或收起“拍摄文件夹”，默认折叠；中央箭头保留，支持 Enter／空格操作。资产归档目录和 SKU 数据库组面板也提供相同的整条边条，SKU 顶部组面板按钮与边条同步，归档和 SKU 面板的折叠状态刷新后保留。目录层级及样式与资产归档一致：磁盘／网络共享按钮下直接列出每次添加或联机存储的拍摄根目录，再向下展开子目录；不展示系统路径的中间父目录，目录树内不列出照片文件。点击目录后，该目录及下级照片在右侧现有缩略图栏显示，RAW/JPG 配对展示。原有左侧照片栏继续保留；窄屏目录栏以浮层显示。

星级使用标准 [XMP-xmp:Rating](https://www.exiftool.org/TagNames/XMP.html)，数据库和文件分别保存。改星、取消星级和撤销均会自动同步，同名 `.xmp` 保留其他软件已有的非评级内容；已存在的 `照片.JPG.xmp` 同样更新，JPG 内嵌评级兼容只读取照片内部元数据的软件。RAW 普通改星不改动传感器文件。新建索引可读侧车星级，明确零星不会重新被末帧规则选中。其他软件需支持 XMP，并按其流程重新读取元数据。目录栏底部显示待写入数及失败状态，可查看错误并重试；文件离线或被占用时数据库评级仍保留，恢复后自动重试。元数据导出前先保存最新星级，导入会恢复目录和评级并对本机可用照片排队同步；迁移照片时请同时拷贝 XMP 文件。

在左栏文件夹名称或路径上右键，可选择 **打开路径** 或 **从软件移除**。移除只让目录退出软件列表，并停止对应现场监控与索引，不删除或修改照片、RAW、侧车文件；内部评级和索引保留，重新添加同一路径可恢复。移除当前目录会切到剩余目录，移除最后一个目录后显示空工作区。

资产归档搜索会跨已添加位置筛选素材：左侧只保留全部命中文件夹及其祖先，自动展开并标识匹配目录，统计覆盖全部搜索分页。点击命中文件夹可只看该目录，点击“全部匹配文件夹”返回所有结果；清空搜索恢复原浏览目录及展开状态。中间图片区按文件夹分组，各组左上显示名称、路径和本页数量，并使用独立边框；点击文件夹标题栏可折叠或展开，折叠状态在自动刷新及重开后保留。大图前后切换沿用当前页面的分组顺序，并跳过已折叠的分组。右侧“素材资料与 SKU”直接复用已解码缩略图，不再单独生成 900px 预览；双击时才进入清晰大图查看。

归档索引完成不等于预览已完成，右侧分别显示小缩略图和清晰预览进度，任一阶段未完成都会继续只读读取源素材。归档元数据监控空闲时使用目录通知，正常通知下每 6 小时补偿巡检，通知不可用时每 5 分钟兜底；手动重扫、源目录变化及失败重试保留。重启后已知且未变化的 JPG 跳过重复解码完整性检查，仅 XMP 变化也不重新解码原图片。搜索与已就绪预览使用本地数据库和图片缓存；本地缓存记账写入不等于改写 NAS 原片。

在资产归档双击图片，右侧“图片元数据”自动读取同目录的 `照片.xmp` 和 `照片.JPG.xmp`（含大写扩展名），完整文件名侧车优先。可编辑标题、描述、关键词和颜色标签，停止输入约 0.9 秒后自动保存，也可点击“立即保存”；切图会提交当前修改，并绑定原照片。JPG 同步内嵌字段及已有侧车；没有侧车时创建完整文件名 XMP。RAW、PNG、TIFF、HEIC、WebP 等通过侧车保存，原文件不改动。只修改 XMP 也能被目录监控感知；保留其他软件的调色、其他语言标题和未知字段，不把调色参数当成画面渲染。外部竞争修改、侧车损坏和文件离线会明确报错，可重新读取后再编辑。归档页“确认 SKU 元数据”同时提交文件写回队列。

第一次批量读取时间等元数据；重复扫描未变化文件使用缓存。索引不预先解码所有 RAW，预览在索引元数据读取期间分批进入持久队列，监控新增照片与添加资产归档文件夹或分区也会自动排队；后台启动时按进程可用 CPU 和可用物理内存自动启用并发，不再固定上限 12 路。每路预览按 512 MiB 估算，并预留至少 1 GiB 或总物理内存的 10%（取较大者），低配置机器最低 1 路；本机 20 个逻辑处理器且内存充足时启用 20 路。各位置共用预览容量和目录枚举池，单位置内部也并行扫描子目录，每个在途枚举批次最多 128 项，边扫描边入库；实际速度仍受原片格式、存储和网络限制。拍摄任务预热 480/1800px，资产归档预热 420/4096px，另保留 2 个前台生成槽。缓存与未完成队列重启后复用，未变化图片不会每次从零构建。选片缓存位于 `.framekeep/previews`，归档沿用 `.framekeep/catalog_previews`。网格、列表与左侧照片栏优先读取 RAW 的小内嵌缩略图（可能只有 160px，缓存保留原尺寸），缺失或损坏才依次尝试配对 JPG、较大内嵌预览和 LibRaw 内嵌图。单张视图优先使用较清晰的预览，工作台不再提供手动 RAW 解码按钮。JPEG 根据预览尺寸缩小解码，已有缓存直接返回。多个窗口的 LR 发送绑定各自页面的文件夹。

照片索引、评级和设置保存在 `.framekeep/framekeep.sqlite3`，与此前演示库分离。项目根启动器使用项目的 `.framekeep`；在本项目 `dist/末帧选片/` 内直接运行 exe 也识别并沿用项目库。移出项目单独使用便携目录时，默认使用程序旁 `.framekeep`；`FRAMEKEEP_DATA` 可显式指定数据目录。预览不写原图。人工标星自动保存到数据库及同名 `.xmp`，JPG 同时更新内嵌 XMP 评级；RAW 的普通改星仅写侧车。主动提交“资产备案”或拍摄段内的 SKU 标签确认后，会按明确选定的策略写入 SKU 等 XMP 元数据，不移动、不重命名原图。

开启“使用内置模型”后，立即在后台静默预加载 GLM-OCR；保持内置模式时重开程序也会提前加载，无需等到标星。准备失败会在模型设置中显示原因，关闭内置模式会取消过期的模型预加载。资源复制/下载提供当前文件的真实百分比；模型启动和 OCR 推理未提供百分比时，显示实际阶段、不定进度条及等待时长。

二星标记后，“款号备案”与中央单张预览同步显示 SVG 标签扫描动画；解析完成后在原位保留 SKU，待确认候选会明确提示核对。暂停、等待模型与失败显示对应状态并停止扫描。设置 → 预览显示 → **解析动画**可选择四角或隐藏，默认右上角、35% 透明度；动画与完成后的 SKU 共用设置并自动记忆，侧栏保持清晰。支持减少动态效果，浮层不拦截图片缩放或拖动，并避让星标与缩放滑杆。

设置 → 预览显示 → 图片缓存可设置 **1–256 GB 整数上限**，默认 10 GB，重启保持；监控、选片和资产归档共用总额度，显示已用空间、预览份数及待生成/失败数量。降低上限时后台每批整理 16 份可信缓存，完成后应用新上限，文件被占用时提示并保留原上限；不影响原照片、评级和元数据。归档缓存命中时不再检查原图是否在线，源目录暂时离线也可继续查看已缓存的尺寸。首次导入仍需读取文件和元数据，完成时间受图片格式、数量及磁盘速度影响。

RAW 旁有配对 JPG 时优先从 JPG 生成预览，随后才尝试 RAW 内嵌预览；小 JPG 一般读取和解码更轻，但预览清晰度受该 JPG 分辨率限制。不会为了缩略图自动展开完整 RAW。拍摄任务的新图片先显示预览，再在后台准备完整内容指纹；归档预生成不为显示预览计算整张原片的完整哈希，导出缓存时再显式准备；跨路径缓存候选可先用少量文件片段排除不匹配项，真正复用前仍需完整 SHA-256 验证。

**缓存位置与换机复用**同样位于“设置 → 预览显示 → 缓存数据库与迁移”。可以选择独立的空文件夹作为缓存目标，点击“迁移缓存并切换路径”。程序先复制并核对已登记图片，再等待在途生成完成、备份 SQLite 索引并原子切换位置；迁移失败继续使用原位置。重启保持新路径。推荐本机高速 SSD；缓存路径不能与原图或软件资料目录重叠，导入照片时自动排除缓存目录。原位置保留恢复副本，确认后可点击“清理旧位置图片缓存”，仅清理迁移清单中登记且内容校验一致的图片，原照片、评级数据库与未知文件保留。外置设备离线时明确提示并临时使用本机缓存，不改写原设备登记；重新连接后重启恢复。

选择备份文件夹后点击“导出缓存数据库与图片”，生成 `.framekeep-cache.zip`，包含缩略图、预览与版本化的分块数据库清单；图片和索引块均有 SHA-256 校验。导入时合并到当前缓存，不直接打开外部 SQL 数据库，不覆盖未知同名文件；重复导入及先添加归档后导入均按内容指纹去重。备份超过当前额度时优先合并最近使用的图片，并报告容量跳过与冲突数。大量记录采用分块读取和本机临时数据库合并。图片额度统计不含索引、导出备份和迁移保留副本。

新机器先导入缓存备份，再添加新位置的资产归档即可；也支持先添加归档再导入。**完整文件内容 SHA-256** 决定图片身份，盘符、目录和文件名不参与；预览尺寸、方向、解码方式和生成版本共同限定缓存。首次匹配需要读取照片内容，但匹配成功无需重新解码，换盘或改名后可复用。相同名称、大小、时间不作为可靠匹配。照片或内嵌元数据实际改变时建立新版本，不误用旧预览。升级前的缓存可点击“补齐已有缓存的迁移指纹”；导出时也会自动准备，原图离线/版本变化而无法校验的条目明确计数并保留原缓存。

缓存备份**不包含原照片、评级、SKU/OCR 业务资料、模型或密钥**；换机时原照片仍需复制，评级与业务元数据继续使用“设置 → 数据库管理”的既有备份。缓存管理任务在后台显示进度，运行期间状态栏提示忙碌。

## 外观主题

点击右上角「主题」可切换 **象牙白、星夜黑、醇白、硬核工作台**，默认星夜黑，兼容原有主题偏好。经典三主题使用磨砂面板、圆润按钮与轻投影；硬核工作台使用中性深色、紧凑三栏和中央大图。覆盖照片浏览、拍摄进度、输入控件、菜单与弹窗。选择后立即生效，刷新或重启后恢复，不影响照片评级和文件夹设置。

「选片 / 拍摄进度 / 资产归档 / 解析任务 / 设置」位于全宽底部标签栏，使用图标加文字和顶部选中线，底栏独立占位且始终可访问，筛选、统计、搜索在下方工具行排列；“当前拍摄”位于选片右侧独立标签页；视图、排序和前后浏览位于中央图片区底部，缩略图滑块在预览区右下角悬浮显示，替代旧的组号/时间说明，窄栏可滚轮横向浏览。将鼠标移到「视图」可勾选显示或收起顶部、左右栏、选片工具，也支持键盘操作。隐藏顶部后左上角保留恢复入口，底部标签栏保持显示。

选片工作台左右面板与中央图片区之间的细分隔线可拖拽调宽，宽度自动记忆。双击分隔线恢复对应栏默认宽度；聚焦后用左右方向键微调，`Shift` 加速，`Home` 恢复默认。左侧监控照片按栏宽和横竖比例自动缩放，图片两侧仅留小间距，保留滚轮、选中细边框与微光；窄屏自动切回纵向布局。

## 选片右侧栏的当前拍摄

右侧栏通过“照片设置／当前拍摄”标签切换，切换偏好刷新后保留。“当前拍摄”页集中显示当前工作表、目录绑定、已拍／待处理数量和“查看识别记录”，下方为“序号、款号、拍摄状态”三列表格。表格按当前工作表去重款号、按原表首次出现顺序从 1 编号；同款任一原表行已拍即显示“已拍摄”，与原进度统计一致。切表、标签识别和人工复核后自动同步，长清单独立滚动，表头及上方控制保持可见。

照片评级和设置保留在“照片设置”页；底部“发送到 LR”在两个标签页下均可使用。侧栏标签支持左右方向键及 Home／End 切换，不切换当前照片。

## 归档与 SKU 图片全屏浏览

“资产归档”和“SKU 数据库”均可双击图片进入全屏浏览，背景模糊并变暗；滚轮或 `+ / -` 缩放，放大后用左键／中键拖拽平移，左右方向键切图，`0 / Home` 恢复适应窗口，`Esc` 退出。右侧磨砂面板在归档页展示文件、拍摄参数、路径和组件详情，在 SKU 数据库展示文件名、拍摄时间、款号及 OCR 原文本；区间继承的 OCR 注明标签来源，缺失拍摄时间显示“未提供”。清晰预览统一最高 2048 像素，放大仅浏览已有预览，不额外生成 4096 或 1:1 预览。

**SKU 数据库媒体池**左侧分为“组”和“SKU 款号”两栏。点击“组”标题旁的 ＋ 创建文件夹，可包含子组；将款号拖到组或“未分组”归类，也可右键“移到组…”操作。组和分类在本机保存，重启保留。右键组可改名或移除，移除组后其 SKU 回到上级。分组是软件内分类，不移动磁盘图片。

“款号清单”和“文件路径”中的款号按钮均显示入库日期；同一款号有多次入库时显示最近一次记录日期，拍摄日期与文件修改日期不替代入库日期。

顶部“组面板／款号面板”按钮可分别折叠左侧两栏，图片区随之扩展；再次点击恢复，刷新及重启后保持。

**设置 → 数据库管理**提供“导出元数据／导入元数据”。导出当前全部 SKU 元数据库为 `.framekeep.json` 文件，包含所有款号、分组、已移除记录、OCR 原文及辅助字段、拍摄区间、照片索引、资产归属、星级和拍摄文档，不受页面搜索或分页影响。原照片、模型密钥和本机自动运行设置不包含在备份中。

换机操作：① 将照片复制到新机器，在“资产归档”添加归档目录；② 到“设置 → 数据库管理”导入原机器导出的 SKU 元数据。系统自动核对永久资产 ID、文件校验值或可靠拍摄身份，将本机照片与备份关联，恢复款号、拍摄类型、项目／区间、星级及 OCR 资料，并将受末帧管理的元数据同步到本机 JPG／RAW 文件。盘符和目录可变化，无需保留旧机器路径；原图离线时仍可查询资料。同步在后台持续执行，设置页显示已同步数量、待写入、复核、失败、未匹配及备份缺图；重启保留进度。已重新关联的离线副本不重复显示，在线副本仍保留。

导入兼容本机已扫描出的相同文件身份，保留已有人工修改；真正的业务数据冲突会撤销数据库导入。同名不足以认定同一照片，匹配歧义、不同人工星级或无法核实的资产身份明确列为异常。重复导入同一备份不重复添加；新增归档后重新导入同一文件，可继续关联。备份有版本及完整性校验，文件上限 200 MB；原机器未完成的识别／写入任务继续暂停，换机同步单独建立本机写入队列。元数据导出不包含原照片；字段级写入与撤销档案保存在 `data/metadata-history/`，不能替代原照片备份。

**导入文档对账**：点击正确 SKU 后，整款入库并写入元数据，同时更新当前工作表对应款号的拍摄状态、照片 EXIF 拍摄完成时间。拍摄进度及自动更新的 Excel 工作副本在“拍摄状态”后显示“款号图片”，默认采用本款第一张商品图，无商品图时回退文档参考图或当前照片；“备注”统一排在最后一列。未拍摄行的“款号图片”列不显示图片或选择入口，原表“图片”参考列保持。点击已拍摄款号图片，只打开该款实际拍摄区间的组图，分页保持当前款号，不能切换为全部 SKU；可选择封面，保存后同款已拍摄工作表、全部汇总和 Excel 同步，取消不保存。只更换封面，不改变照片归属或拍摄状态。原表参考图与完成时间的标签照片仍可放大查看，支持滚轮／加减按钮缩放、拖拽平移、双击或数字键 0 复位和 Esc 退出。Excel 内嵌缩略图，离线也可对账；原始导入文档保留，缺失图片或拍摄时间明确显示。

**清单列名与全部款号**：表头为纯文字，直接双击即可修改，Enter 或失焦保存、Esc 取消；空名称不保存。名称随项目持久保存并写入 Excel 工作副本及最终导出，重新导入改名后的文档仍可识别业务列。右侧工作表分类增加“全部”，按款号合并展示序号、原表行、款号、图片和所属工作表；跨表重复款号只列一行，各工作表对应的原表行全部保留。查看“全部”不会切换当前 OCR 拍摄工作表；导出保留各原工作表并附带“全部款号”汇总页，汇总序号与页面一样从 1 排列。

**表格显示**：拍摄进度及右侧“当前拍摄”表格默认显示半透明横纵线和外框。进入“设置 → 表格显示”，可开关线框、调节 0%–100% 透明度，并在示例表格中实时预览；默认透明度 78%，数值越大越透明，100% 完全隐藏线条。只调整线框，不影响文字、照片和拍摄状态底色；开关与透明度自动保存，重新打开软件保留。

双击 SKU 款号或按 `F2` 修改，回车／保存即更新该数据库款号的全部已登记图片、RAW/JPG 和在线副本元数据，包含同号的多个拍摄区间，不受当前照片分页限制；项目、类型和区间边界保留。图片双击仍进入全屏浏览。已有同名目标 SKU 时提示冲突，不自动合并；原始 OCR 辅助文字保留可搜索。顶部状态显示逐文件写入结果，失败项仍可在资产归档批次重试。右键“移除 SKU”只将该款移到“已移除”，保留照片和已写元数据，可从“已移除”右键恢复到原组，后台刷新不会自行恢复。

## 通用设置

顶部“设置”打开独立页面，集中放置文件策略、明确覆盖已有不同归属、读取所选备案及 SKU 自动区间操作。原资产备案栏只保留日常 SKU、OCR、整款编辑写入及结果，文件策略为“RAW 使用 XMP 侧车，JPG 写入元数据”。设置页显示当前目录、类型和选择数量；“切换当前拍摄”返回右侧唯一类型入口，“返回工作台”回到进入设置前的工作页，保留照片选择及 SKU 草稿。

手工结束区间可在设置页填写封口款号，留空时沿用选片页的 SKU。接续、封口及覆盖仍需要原有明确操作，不因打开设置页自动写入文件。

## 选片

工作页现为「现场拍摄」，日常入口集中在现场监控、实时预览和现场标星；批量添加照片文件夹及时间规则设置不再显示。既有目录、评级和规则数据继续保留，归档目录不混入现场拍摄目录列表。

「资产归档」支持在右侧点选 1–5 星、清星，也可选中照片后用数字键 1–5／0 操作。星级保存在共享索引，缩略图和右侧预览右下角同步显示；J/R 标记自动避让。现场照片与最终归档副本经拍摄身份或永久资产 ID 确认后共享人工评级，后到文件自动继承；归档改星和清星也会反映到现场记录及 LR 导出清单。仅同名、身份不确定的文件继续等待复核，已有不同文件元数据沿用原冲突保护。

- 网格、列表、单张共用评级。单击定位，双击打开单张。大预览区星标默认左下角，可在“设置 → 预览显示”的“星标位置”选择四角或隐藏，与缩放滑杆同页设置；位置即时生效并记忆，与滑杆靠近时自动避让，隐藏后仍可用数字键标星。同页提供星标与缩放滑杆各自的透明度滑杆（0%–100%，数值越大越透明，0% 保持原有外观），即时生效并记忆，100% 时不遮挡照片操作。缩放滑杆默认隐藏，可在“设置 → 预览显示”选择隐藏或四角位置，设置即时生效并记忆；启用后鼠标移入中央照片区域显示半透明悬浮滑块，移开后隐藏；滑块及加减按钮在网格/列表中调整缩略图大小，在单张/对比中控制大图缩放（100%–1600%，100% 为适应窗口），大图滚轮缩放、点击复位与切图复位同步更新百分比；支持键盘聚焦操作。缩略图区也支持 `Ctrl + 滚轮` 调整缩略图。单张及对比图支持以鼠标位置为中心的滚轮缩放（适应尺寸的 1–16 倍），放大后用左键或按住中键拖拽平移，放大后点击照片恢复全图；切换照片/文件夹后恢复适应。
- `G / L / E` 切换网格/列表/单张，`← / →` 切照片，`1–5` 标星，`0` 清除，`X` 暂不选/恢复，`Ctrl+Z` 撤销当前页面操作。
- 网格和列表中按住 `Shift` 滑过照片可连续勾选，无需按鼠标键，也支持按住左键拖选。从未勾选照片起滑为加选，从已勾选照片起滑为取消；本次滑过的同一张只处理一次，加选保留已有高星评级。松开 `Shift`（拖选时松开左键）完成并保存，`Ctrl+Z` 整批撤销，`Esc` 取消本次滑选。筛选中的照片在滑选完成后统一更新位置；`Shift + 单击` 仍用于资产备案范围选择。
- 全部、已选、未选按照片筛选；可叠加文件名搜索、拍摄时间/星级排序。左侧只显示文件夹任务列表，不再显示连拍分组导航；打开旧会话时自动浏览整个文件夹。发送 LR 覆盖整个会话的已选照片，不受当前浏览筛选影响。
- 时间规则默认相邻间隔 ≤ 4 秒为同组，保留末一张或末两张。读取 RAW 子秒和时区信息；缺时间照片单独保留。多机身不会混成同组。
- 人工评级自动入库；刷新恢复设置和评级。撤销历史只保留在当前页面。多个窗口同时编辑同一会话时检测版本冲突，避免静默覆盖；提示冲突后刷新再编辑。
- RAW/JPG 同目录同名配对。单张页可按需生成 RAW 解码预览，目前采用半尺寸输出，界面明确标示；预览不是原始 RAW 的 100% 像素检查。

## 现场监控：照片传入即显示

一次设置后，新照片自动显示，现场只按无线鼠标即可标星，不需要手动刷新或用键盘切图。

可以直接接续其他软件已经拍摄的非空目录：已有照片分批载入并保留原星级，加载期间显示读取进度，新照片继续接入；开始监控会清除旧子目录、搜索和星级筛选，便于查看全部历史照片。选择、扫描、切换、停止和重开监控只读取原照片及已有侧车，不清空、移动、重命名或自动写回已有评级。主动标星和明确提交 SKU 等写入操作仍按原流程同步文件。

1. 点击顶部 **“现场监控”**，选择相机联机、无线传图或其他软件实际保存照片的文件夹。目录可以为空，支持本地盘、已可访问的映射盘/UNC 路径；按需包含子文件夹。
2. 保持 **“自动显示最新传入照片”** 勾选，点击 **“开始监控”**。工作台进入单张模式，照片传入后自动入库并定位最新一张。
3. 再到 **“鼠标遥控”** 启用接收器。每次左键加一星，最高五星；上一张的星级自动保存，后续传入不会覆盖它。新照片从 0 星等待标记，照片文件内已有星级继续保留；开始监控时原目录已有的有效评级也保留。
4. 要回看之前的照片，在现场监控面板取消自动跟随；新照片继续入库，但不会抢走当前照片。重新勾选会跟随最新一张。弹窗或切换其他目录时不抢焦点，回到监控目录后恢复更新。
5. 点击 **“停止监控”** 只停止接收，不删除照片或评级，也不停止已经启用的鼠标遥控。手动现场监控的目录与启停状态保存在本机数据目录，程序重启恢复；Canon 联机则在 EOS 已关联本软件时自动跟随其保存目录；开启鼠标“全自动切换”后，遥控也会在程序启动时自动启用。

Windows 使用原生目录变化通知立即唤醒监控。JPG 写入句柄已关闭、像素流完整且读取前后签名一致时立即处理，不再额外等待固定稳定时间；RAW／其他格式保留约 80ms 稳定检查，分段传输不会显示半张图。同次目录枚举复用文件及 XMP 属性，ExifTool 提前预热并常驻复用，新照片以增量通知页面，不为每张新图重传整个目录或重建完整评级索引。空闲时每约 2 秒补偿重扫，通知不可用时短间隔兜底。自动跟随先显示快速预览，再补齐清晰图；新预览准备好后用 160ms 淡入衔接旧图，手动翻图保持即时，系统“减少动态效果”会禁用淡入。坏文件退避重试，不挡住正常文件；目录离线时保留当前照片并重连。照片仍由相机配套软件、联机软件或同步工具传入目录，末帧不负责相机连接或无线传输。

本机同一张实际 JPG、空目录连续传入的浏览器实测：文件写完至中央图片加载完成由约 1.5–1.7 秒降至首张约 0.5 秒、后续约 0.3 秒；1400 张已有照片目录约 0.6–1.45 秒（包含冷启动及同时运行其他验证的影响）。这些时间不包含相机曝光及传输，不能当成所有设备的保证。预览按文件指纹缓存，标星不再重建中央图片。实现和 Canon DPP 只读分析见 [023-监控预览低延迟优化](开发任务/023-监控预览低延迟优化.md)。

使用增量更新，不整页刷新、不重启遥控、不重建整库，不制造新增照片与人工保存之间的版本冲突。RAW/JPG 先后到达会合并为同一拍摄编号并保留星级；之后停止监控再重新索引也保留此编号。源照片被移出目录时不会自动删除已入库记录；同路径覆盖保留评级，若是新拍摄请使用唯一文件名。监控期间禁止对同一目录启动整目录重新索引。

EOS 已发送实际照片路径时优先局部检查新文件及同名配对，不等待逐张检查全部历史照片。拍摄期间当前预览优先，历史缓存只保留两项同时生成，前台请求完成后继续补齐；停止监控后恢复普通后台并发。

已验证真实 JPG 新增、分段写入、自动定位、暂停跟随、遥控输入包联动、保存及停止/恢复；RAW/JPG 配对使用模拟 RAW 元数据测试，没有把它当作真实相机 RAW 传输验收。详细记录见 [011-监控文件夹现场标星](开发任务/011-监控文件夹现场标星.md)。

在 EOS Utility 的「链接软件 → 记录…」中选择当前安装的「末帧选片.exe」后，程序先读取 EOS 保存根目录等待照片；收到照片通知后直接监控其实际所在日期／自定义文件夹，不再扫描整个历史根目录。EOS 新目录的照片通知自动切换会话，同目录保持监控，旧照片与评级保留。EOS 首选项尚未落盘或仍显示旧 DPP 选择时，真实照片通知仍可接入并持续监控。自动跟随保留 EOS 当前保存路径和命名规则，旧的末帧保存路径不覆盖它。左栏显示「联机拍摄 · 自动跟随」。独立手动监控优先，停止监控会暂停本次接入；关闭 Canon 开关会记住关闭状态，可点击「跟随 EOS 保存目录」恢复。

未关联 EOS 时保持待命，不主动弹窗或写入旧配置。需要由末帧设置新保存位置时，点击「联机拍摄」浏览本地、映射盘或 UNC 共享目录并应用，启用保留原文件名和 `YYYY-MM-DD` 日期子目录的规则；EOS 运行中暂存修改，关闭后应用，再打开 EOS 生效。详见 [Canon 自动联机接入](技术文档/Canon自动联机接入.md)。表格可在未打开照片目录、浏览照片或监控过程中导入，立即显示同名工作表（没有同名则显示第一个有效工作表）的款号，重新导入会清空旧搜索与拍摄状态筛选。无目录时也能切换工作表查看，打开目录后再绑定拍摄。星级按钮位于中央预览左下角，右栏不再重复显示，快捷键和自动保存保持原有操作。

## 无线鼠标遥控

在接收器的无线范围内，将指定鼠标作为末帧当前照片的标星遥控器，无需改写接收器固件。

1. 插入已适配接收器：原无线鼠标 `VID_367B&PID_1919`，或罗技无线鼠标 `VID_046D&PID_C534`，打开新版末帧选片。原 HeartRelay 若开启了专属点赞，先停止其接管。

3. 选择**标星方案**后启用接收器。原“累加标星”沿用左键每次加一星、最高五星；新增“固定标星 · 左键一星 / 右键两星”，左键直接设为一星、右键直接设为两星，同一键在 500 毫秒内双击会取消为零星，间隔单击保持指定星级，左右键可来回切换。长按只处理一次，已有高星或“暂不选”也按本次键指定的星级处理。方案自动保存，重启后保留。
4. 网格、列表、单张共用当前定位；切图后各自保存星级。星级沿用自动保存与 `Ctrl+Z` 撤销；点击时绑定照片，传输延迟不会把这次点击记到随后定位的照片。弹窗、切文件夹期间暂停；旧目录未处理的点击不写入新目录。
5. 点击“鼠标遥控 → 停止遥控”，或按 **`Ctrl+Alt+F11`** 恢复普通鼠标，本次运行不会自动重启；下次启动仍按全自动设置启用。关闭“全自动切换”立即释放本窗口遥控，并关闭下次自动启用。关闭程序、工作台失联超过 10 秒、输入线程错误也会释放接管。页面刷新或另一窗口不会继承已有遥控会话，可先停止再启用。

鼠标遥控设置页提供两个独立按键功能开关，首次均为关闭：累加方案中的**右键减星**每次按下减一星、最低零星，长按不连发；**滚轮浏览**向上上一张、向下下一张，首尾不循环。固定方案的右键始终标两星，减星设置在返回累加方案时继续保留。保存后立即生效，重启保留选择；是否自动启用遥控由“全自动切换”控制。滚轮浏览后紧接着按左键或右键，星级绑定切换后的照片。两种方案均沿用撤销、自动保存、归档共享和二星 SKU 标签规则。

开启遥控期间，这只鼠标的移动和未启用功能的输入被隔离，左键用于标星，开启的右键/滚轮功能仅作用于工作台，其他鼠标照常操作。恢复键注册失败、多只同型号接收器或目标被其他工具占用时拒绝启用。进程锁从首次连接输入服务保持至程序退出，阻止另一末帧进程同时枚举/接管；不同工作台窗口共享同一引擎时只能由一个窗口接收遥控。原 HeartRelay 正在专属点赞时拒绝接管，使用标星时建议退出原工具，避免再次开启点赞。新工具不使用 HeartRelay 已占用的 `Ctrl+Alt+F12`。

当前支持已核实 SHA-256 的官方签名输入驱动。完整安装阶段和进入鼠标遥控时自动检查；缺少时准备官方安装器并请求 Windows 授权，已有异版驱动会明确提示且不覆盖，不热重载设备。驱动与程序使用仍受目标 Windows 的签名与安全策略约束，系统阻止安装时须依据具体错误处理。遥控只接管已适配的原无线鼠标 `367B:1919` 或罗技 `046D:C534` 鼠标接口，保留紧急恢复。鼠标事件只进入本机工作台，不向任意系统窗口发送按键；在 Lightroom 中写星仍使用现有“发送 LR”桥接与预览确认，不会直接编辑原图。

## AI 助手配置

2026-10-19 已移除 AI 选片、拼版分析、AI 建议/记录/复核和模型选片请求。时间规则、人工标星、RAW 预览和 LR 桥接继续可用。

顶部「AI 助手配置」现在按多模态、OCR、文本展示配置卡片，可添加多种模型。点击“保存卡片”仅保存配置；“保存并选用”会同时设为该类别当前模型，也可点击已有卡片切换选用；删除选用卡片后需重新选择，不自动切换其他配置。文本类别预留给后续功能，不参与 SKU 视觉识别。密钥不回传页面，使用 Windows DPAPI 保护后保存到 `data/model-providers.json`；留空编辑保留原密钥。已有 Markdown 配置可导入多模态卡片，`FRAMEKEEP_CONFIG` 兼容保留。配置保存成功不表示已验证远端接口。

新增/编辑卡片时，填写接口地址和 API 密钥，等待自动获取或点击 **“获取模型列表”**，搜索并选择模型即可填入模型标识，再保存卡片或保存并选用。编辑卡片时密钥留空会使用本机已保存密钥获取列表；LM Studio 本地服务无鉴权时可不填密钥。Chat/Responses 兼容协议自动探测 `/v1/models`、`/models` 及用户指定的路径，填写完整 `/v1/chat/completions` 或 `/v1/responses` 地址也可获取。列表不会自动判断视觉能力，不发送图片、不执行推理、不自动保存或改选；空列表、无列表接口或 OCR JSON/PaddleOCR 服务可继续手填模型 ID。

多模态支持 OpenAI Responses、Chat Completions 兼容协议；OCR 可用上述视觉协议、OCR JSON 或 PaddleOCR。OCR JSON 接口接收 `model,image_base64,prompt`，返回 `text,codes,confidence,is_label,handwritten`；`confidence` 为 0–1，低置信转人工复核。PaddleOCR 接收 `file,fileType=1`，读取 `result.ocrResults[].prunedResult.rec_texts/rec_scores`，实际模型由 OCR 服务部署决定，卡片模型名称用于标识。接口支持任意主机的 HTTP/HTTPS。可输入 IP+端口、域名+端口或域名，离开地址/密钥输入框后自动补齐协议、测试模型列表路径并回填成功地址；明确填写的协议保持不变，未填协议时先按主机和端口选择协议，失败再探测另一协议。自定义路径及完整 Chat/Responses/Models 地址也可使用，保存后识别共用成功路径。

升级时已采用的历史 AI 结果会一次性固化为普通评级，连同人工修改、未选和排除状态保留，避免回到时间规则后改变已选集合。旧分析记录留在本地数据库，已无执行或采用入口；旧分析接口返回 410，旧窗口须刷新。迁移在数据库事务内执行，历史结果不完整或已过期时停止并报错，不猜测评级。

本机三个会话共 4447 个拍摄编号的隔离副本已逐张核对，迁移前后评级/排除/文件路径完全一致，其中 0811 的 48 张已选保持。无线鼠标接入状态见上方专节。

添加或编辑 API 卡片时可设置 **最大并发数（1–64，默认 4）**，卡片会显示保存的上限，重启后保留；既有 API 配置未填写时兼容为 4。建议与服务端并发一致。同一卡片的 OCR、二星和多模态请求共用上限，不同卡片独立；修改后对后续请求生效，不中断正在执行的推理。内置模型固定为 1，解析页的“本机模型并发”控制本机资源，API 使用卡片设置。

## SKU 标签与拍摄对账

也可直接在顶部「现场监控」窗口将包含款号的 `.xlsx`（不超过20MB）**拖入“拍摄计划文档”区域**，松开后自动读取；也可点击 **「导入拍摄计划文档」** 选择文件。每次导入一份，系统自动读取款号、工作表及数量；选择本次拍摄类型后点击「开始监控」，计划会绑定到窗口内的照片传入文件夹。单个有效工作表自动选中，多表需明确选择；导入的任务同时显示在「拍摄进度」及右侧资产备案类型选项中。

1. 在「AI 助手配置」添加并点击选用 OCR 或多模态卡片。可两类各选一个，手写模糊匹配建议同时配置两个不同模型服务。
2. 打开现场照片目录，点击「拍摄对账 → 导入 Excel 建立任务」，上传本次 `.xlsx`（不超过 20MB）。自动寻找各页款号列；每页在实际活动列末尾添加或复用“拍摄状态”，不修改源表。
3. 在常驻的「当前拍摄」选择工作表，例如“娴姐”或“细节图”，并绑定当前照片目录。未选择页时不会自动识别；相同款号在不同页独立统计，切换页不改变已经入队标签的归属。
4. 拍完一款后拍摄清晰款号标签，点击二星、按键 2 或遥控设为二星后立即保存并触发解析，无需保持 1.2 秒。选用 API OCR 时，新二星与普通解析并发执行，遵守该卡片的“最大并发数”；容量满时最新二星优先使用下一个空位，已发出的请求继续运行。普通 API 批量解析也按卡片容量并行，不再固定为 1 或 2 路。建议与服务端设置一致（例如 LM Studio 的 4 并发），服务端仍可能有自身排队。请求发出后再处理归档区间，归档写图不挡住最新二星 OCR。内置 local 模型仍遵守本机资源限制。暂停或手动模式仍按任务设置控制；全自动 OCR 开启时，尚未扫描到的二星也立即入队。也可在「拍摄进度」点击“识别当前二星标签”，在“识别记录与待确认”查看和复核结果。快速经过二星后改为其他星级，可能已发出识别请求，但取消二星后不提交该标签的识别贡献；撤星重标后，旧请求晚返回不覆盖新结果。未配置模型时保留等待记录，选用后恢复。两次按键表示普通星级从 0 到 2，已有星级按原规则递增。
5. 高置信唯一精确结果自动标“已拍摄”。不确定结果在「识别记录与待确认」查看标签图、原文、候选及所属页，选择本页准确款号再确认。取消二星或撤销识别会撤销该标签的贡献，其他有效标签及原表已有状态仍保留。

内置及 LM Studio 的 `glm-ocr` 使用原生 `Text Recognition:` 提示读取图片，不要求模型输出 JSON。其他服务不支持 `json_object` 参数时，标签识别会在明确的格式参数错误后去掉该参数重试。只返回全文的 OCR 仍展示读取款号和原文；未提供置信度时保留为待确认，不虚构高置信度或自动选择近似款号。
搜索款号时，款号清单标题行居中显示各工作表的匹配数量，例如“款号搜索结果：娴姐 2张，细节图 2张”；右侧工作表标签显示“匹配数量/总款数”。数量随搜索与状态筛选实时更新，按款号去重；清空搜索后标签恢复“已拍摄/总款数”。

拍摄结束后，在“拍摄进度”页右侧栏底部点击 **“导出拍摄记录”**（任务设置收起时也可用）。导出原清单的全部工作表，包含当前已确认的拍摄状态和完成时间，保留图片、样式、公式、分页及原行位置，不受当前页或搜索/筛选影响。桌面弹出另存为，浏览器下载 `.xlsx`；建议文件名为“原文件名-拍摄记录-YYYYMMDD-HHMMSS.xlsx”，方便分次归档。

6. 对账表支持产品图缩略图与点击放大。WPS `DISPIMG` 内嵌图及标准浮动图直接从文件内部读取，不依赖公式计算，不下载外链。搜索/筛选后可「导出 Excel」另存；导出遇文件占用时识别结论仍在数据库，关闭占用后重试。

手写匹配先规范全半角、大小写和分隔符，保留 O/0 等字符区别，再以带转置的加权编辑距离排名。单个易混字符代价 0.2，普通增删改为 1，转置为 0.7；仅两路不同 URL/模型同时指向唯一候选、置信度均 ≥0.9、相似度 ≥97%、改动代价 ≤0.35、与次名差距 ≥6% 才自动通过。相似度是字符匹配分数，不是正确概率；重复款号、多码和相近候选交由人工复核。

数据独立存于 `data/sku.sqlite3`，每次任务的源件副本和工作 Excel 在 `data/sku-projects/<任务ID>/`。导出保留原图片、样式和公式；WPS `DISPIMG` 是专有图片公式，通用表格渲染器或部分 Excel 版本可能显示 `#NAME?`，腾讯文档/WPS 的支持不同。末帧产品图预览可独立正常显示。具体设计和验证见 [012-SKU标签识别与拍摄对账](开发任务/012-SKU标签识别与拍摄对账.md)。

## SKU 区间备案、批量元数据与资产库

选片页右侧“资产备案”的 SKU 输入框下方提供 **OCR 解析当前图**：优先使用当前选用的 OCR 模型，未选 OCR 时使用 SKU 多模态模型。不要求二星或导入 Excel，只解析当前查看的一张图；单个款号填入输入框，多个款号可点选，并可展开 OCR 原文核对。点击推荐款号即确认并提交元数据写入，二星款末标签处理该款完整区间，不需要再确认一次。需要手动修正时，点击“写入 SKU 元数据”进入整款编辑，修改后一次更新。不会改变星级。解析期间切换图片或手动编辑款号，迟到结果不会覆盖新内容。

右侧“款号备案”位于“当前照片”下方，选片和联机监控均默认展开，可自行折叠并保存偏好。普通点击选一张，`Shift + 点击` 连选当前显示顺序中的范围，`Ctrl + 点击` 增减选择；网格、列表、左侧缩略图共享备案选择。该选择与星级/选片复选框独立，切换筛选/排序/目录会重置范围，新传入的照片不会自动加入已有选择。

中央预览在无图片时显示“光轨传片”SVG，首张照片就绪后自动替换；减少动态效果时使用同款静态图。鼠标停留预览区不再弹出缩放／拖拽提示文字，操作说明仍可从帮助中查看。

备案类型沿用当前拍摄工作表／手动类型；修正已备案的整款时沿用该款原类型。从该款任意一张照片点击“写入 SKU 元数据”，弹窗按既有款末边界定位完整区间，列出整款图片（含标签）及 RAW/JPG 文件，可直接修改 SKU；点击“更新整款元数据”一次完成提交，不再经过确认页。此操作明确修正整款原归属并更新 OCR 主款号，保持区间身份；相邻款、其他目录和未封口尾部不随之修改。即使相邻两款使用同一 SKU，也按各自拍摄区间独立更新。无可定位区间时，弹窗明确使用手动选择的照片范围，保留手动备案锁定。关闭／取消编辑不写入，编辑期间区间或归属发生变化需重新打开。同一拍摄资产已登记的 RAW、JPG 和在线副本分别写入，只有 JPG 时先写 JPG，后到 RAW 由既有补写流程继承最新 SKU。结果分别显示 JPG 已内嵌及 RAW 伴随文件的数量；失败文件明确列出原因。写入批次可在“资产归档”查看逐文件结果、重试失败项和撤销；后续已改归属或字段有外部修改时，不直接覆盖恢复。

文件写入规则：

- **RAW 侧车与 JPG 元数据**：RAW 新任务在照片旁写同名 `.xmp` 小档案，不修改 RAW 字节；JPEG 保持文件内写入兼容。档案包含 SKU、永久资产/文件 UUID、拍摄类型、项目、区间、版本及标准关键词 `SKU:…`、`ShootType:…`。移动或改名 RAW 时须一起携带同名侧车。其他未支持格式明确报告失败。
- **历史兼容**：历史 RAW 内嵌批次仍按原策略查看和撤销；尚未准备的旧写入任务与新拍摄区间使用侧车。RAW 有侧车时优先读取其中的备案字段，不以旧内嵌值覆盖新归属。

RAW 新任务默认使用同名 XMP 侧车小档案，JPG 保留文件内元数据兼容。撤销档案保存在 `data/metadata-history/*.json`，只记录字段修改前后值、文件身份及校验值，不长期复制整张原图。JPG 或明确选择内嵌的历史任务在内存中生成结果，核对非目标字段、JPEG 像素/RAW 感光数据和版本后直接写回，不生成整图磁盘副本。写回期间拒绝并发写入和替换；普通异常尝试用内存原内容恢复，强制终止或断电无法保证恢复。元数据改写会改变文件哈希，资产 UUID 与历史哈希分开保存。已安装且完整验哈希的运行时下载压缩包自动释放；成功安装更新不长期保留压缩包、解压目录和回滚整包。

资产备案中的“OCR 解析当前图”默认展开原文，并把推荐款号显示为按钮。原文逐行显示为同款紧凑按钮，也可点击应用；模型名称保留为来源说明。点击正确款号即可确认并应用，沿用现有单张／款末区间入库规则，无需再打开资料弹窗确认；按钮显示“应用中／已应用”。推荐有误时，仍可打开“OCR 资料 / 选择 SKU”，点击原文填入后确认，或手动填写正确款号。设置 → 款号匹配规则默认启用 LC 前缀；OCR 款号包含配置的前缀、后缀或文字时，唯一有效命中就自动应用，手动解析不依赖“全自动 OCR”开关。已有三种规则均按文字包含匹配，完整款号等于配置值也能命中。配置可保存并重启保留；多个不同款号仍保留选择，已有确认和人工归属不会被自动覆盖。规则忽略大小写、全半角和常见连字符差异，兼容连字符周围及字母数字之间的横向空白；款号需含数字，长度筛选先于唯一性判断；删除全部规则可恢复手动确认。

相同 Excel 文件再次导入会直接复用原拍摄任务，保留进度、时间、封面、已绑定目录与当前工作表，并提示“已复用原任务”；文件改名也不会重复添加。按最初导入的文件内容判断，同名但内容已改变的文件可建立独立任务。已移除的旧任务不参与复用，重新导入会建立新进度。

SKU 款号输入框可直接修正整款：手动输入后，下方“OCR 解析当前图”变为“确定”，点击或按 Enter 即将输入的款号应用至当前 SKU 区间全部图片，包含二星标签与产品图；无识别结果、识别失败或正在识别也可确认。再次输入并确定使用最后一次文本，按输入原样更新，手动确定不另加重拍后缀；相邻区间保持。旧 OCR 回包及旧元数据任务不会覆盖新确认。清空手动输入恢复 OCR 识别入口，原始 OCR 资料保留。

同一款产品重复拍摄时，首次保留原 SKU，新的二星款末标签再次确认同款后，整款照片自动使用 `原款号-A`、`原款号-B`，依次到 `-Z`。同一标签重新解析、清零重标或重启保留原版本，不反复递增；历史确认不批量改名，已被真实款号占用的后缀会跳过。版本在本机资料库内按原款号分配，随元数据库备份迁移。拍摄进度仍按原文档款号对账，显示本次带版本 SKU 和对应商品图；原始 OCR 文字保持。A–Z 用完或追加后超过 80 字符时明确提示，保留已有版本。

设置 → 款号匹配规则中的“推荐款号字符数”支持严格大于／小于阈值，留空表示不限；同时填写时取交集，例如大于 5、小于 12 只推荐 6–11 个字符。去除首尾空白、统一全半角后计数，内部连字符计入。启用长度筛选后，原文里的含数字编码也参与推荐；不符合长度的内容不推荐、不通过前后缀自动应用，原文仍完整保留并可手动选择。设置持久保存，已展示推荐即时刷新；不会自动改写历史已确认款号。超过 80 字符的原文可查看，点击提示手动填写其中的款号。

现场区间：先导入 SKU 表、选择拍摄页并绑定目录，再在顶部“设置”页的“SKU 自动区间”接续拍摄段，RAW 使用 XMP 侧车，JPG 更新文件元数据。视觉模型确认 SKU 后自动备案并写入该区间照片，无需勾选开关；所选照片的 SKU 自动填入右侧款号框，后续仍可 Shift/Ctrl 多选、手动批量修正，已人工修正的归属不会被自动结果覆盖。首次自动纳入当前目录尚未归组的照片，首张可为产品图；按款末二星标签结束本款，无需勾选起点。全自动二星识别及“OCR 资料 / 选择 SKU”的确认共用完整区间入库：首款从第一张产品图到首个款末标签（含标签）全部入库，第二款从上一标签之后开始；旧版仅入库标签时，重新确认该标签的 SKU 可补齐前面产品图。重复接续保留当前待封口照片，已经由其他拍摄段接管的图片不重复归组。“产品图 → SKU A 结束标签”归 A，“A 标签后产品图 → SKU B 结束标签”归 B；标签作为证据另计。未读清的标签保留边界，不合并下一款。切页开启独立拍摄段；迟到图片列为待确认，可手工选择备案。最后一款可补标签或填写 SKU 后“手工结束”。RAW/JPG 后到组件沿用同一资产和已经提交的归属。

顶部“资产归档”是独立工作页，按 SKU、类型查询，支持分页、详情/写入历史和当前页 JSON 导出。文件分散或改名后，在“移动后的目录完整路径”扫描并重新定位，同一资产可保存多个位置，离线位置保留记录。资产库是 `data/asset_archive.sqlite3`，照片数据不嵌入数据库。重新定位是读取身份和更新索引，不能在未知目录/离线磁盘上即时发现所有副本。

## 最终归档文件夹一键同步

现场相机只传 JPG 到电脑即可，RAW 留在存储卡。在末帧完成 JPG 标星和 SKU 区间备案后：

1. 将存储卡数据复制到 NAS。
2. 在右侧“归档同步”点击 **“选择最终拷贝路径”**。
3. 点击 **“写入元数据”**，自动递归匹配并写入星级、SKU 和拍摄类型。程序自动进入“解析任务”页，活动任务置顶，显示百分比动画、逐文件写入与最终校验；现场星级/SKU 变更会继续同步到最终目录的 JPG/RAW。写完自动核对字段、漏图及缺少的 RAW/JPG 组件，异常可点击“处理异常”核对，重启后仍可查看结果。

支持 JPG / CR3 / ARW、本机/映射盘/UNC 路径；无需保留现场 JPG，无需打开目的地目录。已选路径会记住；再次写入会检查新拷入文件，已一致的文件不重复改写。结果只显示简短数量，异常时可查看明细。

匹配采用相机型号、机身序列号、原始拍摄日期时间和子秒，再结合原图标识/原始文件名/相机文件编号。不同日期同名文件不会仅靠文件名配对；重复来源或证据不足保留待确认。只同步已经保存的人工星级（含 0 星；排除映射为 0）或 JPG 文件已有真实评级，不把时间规则推荐当作人工星级。JPG 没有明确评级时保留 RAW 原星级。

RAW 已有不同星级/SKU、同名 XMP 冲突或 RAW 已独立备案时不静默覆盖；可查看证据确认，目录中的不同人工评级需先核对。JPG 尚无 SKU 时可以先同步星级，后续备案后再补 SKU。RAW 与 JPG 归为同一拍摄资产、各自保存文件身份和位置；配对、写入、备份和恢复记录均在资产库内。

已验证公开 CC0 Canon R6 Mark II 普通 RAW/C-RAW 样片以及 Sony ARW 副本。CR3 写后感光数据、内嵌 JPEG、全部 mdat 图像负载不变，原始公开样片校验和保持。实测读取/写回使用 ExifTool 与 LibRaw，未声称完成真实相机卡传输或 Lightroom GUI 重新导入验收。实现与验证见 [014-JPG现场评级与后拷RAW自动补写](开发任务/014-JPG现场评级与后拷RAW自动补写.md)。

## 解析任务与自动／手动控制

底部任务进度栏的“清理已完成”移除所有类型的成功完成记录，重启后保持清理状态；识别结果、SKU 数据、对账证据和归档目录配置继续保留。等待、进行中、失败与待复核任务不清理，重新执行的任务会再次显示。

顶部“解析任务”统一监控 OCR 和多模态任务。进度列表展示照片、自动／手动来源、排队／解析中／完成／失败状态、结果和错误原因，可按类型和状态筛选。上方统计包含全部任务，列表各展示最近 100 条；整体进度按实际已结束任务数计算，单图请求中不虚构内部百分比。

- OCR 默认自动：二星标签沿用已绑定工作表的原识别和拍摄对账规则。切到手动后，不再自动提交二星任务，未开始的自动任务等待恢复；手动“OCR 解析所选照片”不要求二星或 Excel，只读文字并保存结果，不记账、不备案。原“资产备案”中的手动 OCR 结果也会记录到任务页。
- 多模态默认手动：先配置并绑定多模态模型，选择解析方案，再提交所选照片。启用自动时绑定当前目录与当前方案，只处理之后新入库照片，不回溯已有照片，不因同一照片补入 RAW/JPG 或写入元数据重复提交。切换目录或方案后，可点击“自动解析使用当前目录与方案”更新绑定。
- 两类队列可分别暂停／恢复，任务可取消或失败后重试；OCR 标签待复核结果仍在拍摄进度页确认。模型请求已经发出时允许完成，未发出的任务遵循新模式。模式、自动目录与方案、暂停状态在本机持久保存，重启恢复。

## LM Studio 本地视觉解析

在“AI 助手配置”点击“添加 LM Studio 本地视觉”，填写已加载的模型 ID（例如实际 Qwen VL 视觉模型），默认接口 `http://127.0.0.1:1234/v1`。保存后，在“资产视觉解析模型”明确选用卡片；这与 SKU 类别选用独立。可测试 `/v1/models` 和实际图片请求；仅模型列表成功不代表支持视觉。支持 Chat/Responses 协议，JSON 模式可关闭；HTTP 400 不支持格式参数时保留提示词约束并重试，返回仍须通过方案校验。密钥仍用本机 DPAPI 保护，不写任务快照。

顶部“解析任务”是独立工作页，沿用选片页的所选照片范围，可建立解析方案：名称、指令和 JSON Schema（顶层 object），保存成不可覆盖的新版本。维度由使用者确定，系统不预设业务必填项；未选择方案不启动解析。选好工作台照片后提交，RAW/JPG 每个拍摄资产只使用一张代表预览图。结果和原文保存在独立 `data/vision_analysis.sqlite3`，按资产/方案/模型版本追踪，AI 不覆盖权威 SKU。

默认两张并发，普通视觉任务与 SKU 标签共享全局容量 2，标签优先；可改为 1、暂停/恢复、取消和重试失败项。每张独立请求，乱序返回仍绑定各自资产。源图/方案/模型输入相同的任务去重，版本变化生成新任务，旧结果保留；源图在请求期间变化会标 stale。并发是客户端请求容量，LM Studio 的实际执行速度还取决于模型和显存，真实本机模型需自行连接测试。此次验证使用本地模拟 HTTP 服务，不代表已经加载用户的 Qwen 模型。

服务提供 `/api/assets`、`/api/assets/<id>`、`/api/archive/selection`、`/api/metadata/preview|apply|retry|revert`、`/api/analysis`、`/api/analysis/schemas|batches|control|results` 等本机接口，修改操作沿用工作台令牌。详细实现与验收记录见 [013-SKU区间元数据与本地视觉资产归档](开发任务/013-SKU区间元数据与本地视觉资产归档.md)。

## Lightroom 桥接

首次点击工作台「发送 LR → 安装桥接插件」，或双击 `安装LR桥接.cmd`。在 Lightroom Classic「文件 → 增效工具管理器」添加：

`%APPDATA%\Adobe\Lightroom\Modules\FramekeepBridge.lrplugin`

运行「图库 → 增效工具额外选项 → 连接末帧工作台（自动重连）」。然后工作台点击「发送到 LR → 发送当前已选星级」，LR 会显示匹配与写入预览，用户确认后批量写星并回传结果。选片清单由后台处理，无需手动下载；桥接插件保留导入已有 `.framekeep.json` 的兼容能力。

桥接只修改已经导入 LR 的目录记录，不修改 `.lrcat` 数据库文件或原图。默认保护已有 2–5 星，未列出的照片不改动；同一任务回传重试不重复弹窗。预览后若星级被其他操作修改则跳过。立即 `Ctrl+Z` 或运行「撤销上次末帧同步」可恢复；插件撤销只在当前插件会话有效，且不会覆盖同步之后的人工修改。

### 已经导入但匹配为 0

不需要重复导入。桥接先尝试同机映射盘/UNC 别名，仍无匹配时只读 LR 全目录路径元数据，寻找源目录同名、相对路径对应且唯一的目录；匹配后仍需核对写星预览。跨盘副本按日期目录名与相对路径定位，不进行文件内容哈希验证。若存在多个副本，必须手动选择映射目录，不能只凭文件名猜测。选的是 LR 实际导入的那个日期文件夹，不是上级目录。

某个验证文件本身可能未导入。本次真实诊断：源文件夹有 1947 个编号，LR `2026-10-14` 目录只有 1701 张，`XSY_0927` 不在 LR 内，`XSY_0929.CR3` 在。后者已实际验证匹配 1 张、修改 1 张、冲突/缺失为 0。其配对 JPG 未作为独立目录项存在，单独报告为伴随文件，不影响 RAW 写星。

插件升级后须在增效工具管理器重新载入，LR 不会自动替换内存中的旧代码。工作台未启动时新桥接在后台重试；当前对话框未关闭时不会继续处理下一条同步。

## 桌面架构与性能边界

Rust 负责窗口、单实例、原生目录/保存、关闭握手及后台进程生命周期。既有 Python 引擎负责 SQLite、ExifTool、RAW 解码和 LR 协议，作为随包附带的本机进程运行。UI 不包含 Electron、Node.js 或独立 Chromium 分发；RAW/NumPy/Python 运行库仍计入完整包体积，不能把 Rust 主程序大小当作整个安装包大小。

浏览仅渲染当前网格、列表或单张，避免同时生成不可见照片表格。实际首屏就绪时间记录在数据目录 `desktop-metrics.json`，不包含整个目录全部预览下载完成；内存应计入桌面主程序、选片引擎及 WebView2 子进程，不能只报 Rust 进程。

## GPU 媒体加速

兼容的 NVIDIA 显卡自动启用 GPU：JPEG 和 RAW 内嵌 JPEG 优先使用 nvJPEG 混合解码，CUDA 完成抗锯齿缩放与 EXIF 方向处理；其他图片和完整 RAW 解码后的像素也可由 GPU 缩放。OCR 请求及旧客户端需要 JPEG 时优先使用 GPU JPEG 编码。缓存命中直接复用已有文件，不强制重建。

视频封面与播放优先使用 CUDA 解码/缩放及 NVENC 编码；ProRes、DNxHR 等不受消费级硬件解码器支持的素材，使用 CPU 解码后交给 GPU 缩放/编码。驱动或格式在准备阶段不兼容时自动回退；极小视频保持原尺寸并使用兼容路径。独立兼容视频组件支持本机 580.97 驱动，不要求更改系统驱动。

在「设置 → 预览显示」查看 GPU 就绪状态及实际照片处理数量。RAW 容器解包、完整 RAW 的 LibRaw 处理、PNG/WebP 等非 JPEG 的解码仍使用 CPU；默认缓存已改为嵌入 JPEG，超过 2048px 才缩小，不再生成 WebP；不将这些环节称为 GPU 解码。未检测到兼容 GPU 时继续使用 CPU，显卡不可用不影响已保存的预览。诊断可通过 `FRAMEKEEP_GPU=off` 临时关闭加速。

开发机执行 `python -X utf8 选片助手/setup_gpu.py` 与 `python -X utf8 选片助手/setup_gpu_video.py` 准备经过固定 SHA-256 校验的运行库；完整安装包已包含这些组件，无需用户安装 CUDA Toolkit、PyTorch 或 Python。运行库许可证随包保留。`python -X utf8 选片助手/benchmark_gpu_media.py --output build/gpu-media/photo-benchmark.json` 可复跑合成 JPEG 热缓存对照，结果不等同于所有实拍素材或 NAS 冷读性能。

## 百万资产检索与 Everything 文件查找

顶部“资产归档”支持 SKU 精确/前缀检索，拍摄类型填写完整名称，项目 ID 可选；每页 60 项，以 SKU、登记时间和资产 ID 稳定排序，通过游标翻页，不在每次查询时统计全库。资产库保存 SKU 与文件身份，Everything 负责查找图片文件名/路径，不直接读取 Everything.db，也不让 Everything 代替 SKU 数据库。

新增监控或资产归档文件夹时，程序自动尝试连接当前用户的 Everything；设置 → 预览显示会显示连接状态。依据官方 SDK/IPC 的[目录查询规则](https://www.voidtools.com/support/everything/searching/)，仅查询所添加根目录的图片候选，监控首批最多 128 个文件、归档最多 2048 个；每次独立子进程查询限时 1.5 秒。候选须经过目录边界、排除目录、链接与实际文件检查后才读取。监控提前准备预览并复用已读元数据；归档首批立即提交供浏览并预热。随后仍进行流式目录核对，补齐新增和未被 Everything 收录的图片；索引缺项不会直接将历史照片标为离线。子目录读取失败时保留原有在线记录并提示，Everything 缺失、未就绪或超时自动使用目录扫描；不修改 Everything 设置、重建索引或直接读其数据库。

缓存层已完成百万条预览索引 + 百万条持久队列合成压测：状态读取 P95 5.47 ms、缓存命中 P95 18.42 ms、任务领取 P95 26.08 ms，受限启动核对 0.72 秒、RSS 增量 4.02 MB。索引约 724 MB，仅有 64 张真实小 JPEG，环境为本机 Windows/热文件缓存；不代表百万原片解码、冷盘/NAS 或百万 UI 卡片实测。缓存计数由事务触发器维护，排队/迁移元数据分批读取，启动每次最多核对 256 份登记图片，其余按访问验证。可复跑 `python 选片助手/benchmark_preview_scale.py --rows 1000000`，实测结果见 `build/cache-scale/result.json`。现场目录超过 2000 张后自动按最多 240 张分批读取，搜索、排序和计数覆盖全目录，网格/列表只绘制可见行；已验证十万条合成记录的有界响应与真实浏览器操作，未宣称百万实拍单会话端到端支持。

展开“文件位置搜索 · Everything 辅助”，输入文件名或完整路径片段后点击“查找文件”。已备案路径显示关联 SKU；新位置显示候选，填入目录并“扫描并重新定位”后才核验文件身份。文件同名不表示同一照片。Everything 未启动/索引未就绪/查询超时会回退本机已备案路径，页面显示覆盖范围；网络盘和未索引磁盘不保证能被 Everything 找到。

本机便携包已包含官方 SDK 适配组件；其他开发机器可先安装 Everything 并等待索引就绪，然后在构建前执行：

```powershell
python -X utf8 选片助手/setup_everything.py
python -X utf8 选片助手/build_release.py
```

安装脚本核对锁定 SHA-256，只下载官方 MIT SDK，不修改 Everything 设置或索引；SDK 和许可证放在忽略的 `.runtime/everything/`，随包复制到 `runtime/everything/`。没有组件时仍可使用元数据检索及备案路径回退。

百万合成资产（双组件、双路径）本机基准：最终引擎 HTTP 检索 60 项 P95 约 28 ms，Everything 单次约 369 ms；前者在造数后的 OS 文件缓存下测试，均不含原片读写、缩略图及界面渲染，不能作为冷盘/网络盘保证。完整方案、实测条件、容量与后续全文检索设计见 [015-百万资产检索与Everything适配](开发任务/015-百万资产检索与Everything适配.md)。全局归档库已分页；现场拍摄工作台仍按会话加载，不宜把全部百万照片塞入单个现场会话。

## 选片与拍摄进度标签页

误移除拍摄文档后，重新导入表格，点击右侧“拍摄文档”或“拍摄进度”页的 **同步拍摄进度**。程序优先使用当前监控文件夹，暂停监控时使用当前打开的照片目录，将有效已确认的拍摄记录回填到对应工作表，并更新软件管理的 Excel 工作副本。完成时间和照片证据保留，重复同步不会重复计数；待确认标签单独提示，临时插拍单独归类。原有工作表选择、拍摄绑定和 OCR 设置保持。

主导航“选片／拍摄进度”位于顶部居中；工作表标签、任务设置、进度统计、识别和筛选工具、导出及提示信息位于拍摄进度右侧栏，主体只显示始终展开的款号清单，旧的收起状态不再生效。右侧标题居中，标题下的款号搜索/状态筛选常驻，搜索结果在款号左侧纵向显示该款号所在的全部工作表按钮，当前页突出显示，点击可切换核对且保留搜索条件；中间设置与记录独立滚动，底部的“导出拍摄记录”“返回选片”等宽等高并固定显示。窄窗口点击“拍摄设置”从右侧展开，点击“收起设置”或 Esc 关闭。拍摄对账按源Excel工作表显示为独立标签，任务设置折叠后仍可切换；左右/Home/End移动标签焦点，Enter或空格确认。款号清单最左侧新增“序号”，按当前列表从1连续排列，已拍置顶和搜索/筛选后重新编号；“原表行”保留供核对，序号只用于页面显示。

顶部“选片”保留原有浏览、鼠标标星与现场监控；“拍摄进度”展示已导入 Excel 的工作表、产品图和原表字段。选择当前拍摄页后，二星 SKU 标签识别匹配或人工确认成功，会将对应款标为“已拍摄”并在页面置顶，显示该页总款数、已拍摄、未拍摄和完成比例。同页重复款号按款去重统计，原表行全部保留；不同工作表独立记账。

“拍摄状态”右侧增加“拍摄完成时间”，取标签照片的 EXIF 原始拍摄日期、子秒和已有时区，点击页面时间可回看标签。缺失时间时显示缺失，Excel 留空，不使用文件复制时间或识别完成时间代替。同款有多张有效标签时取最近的有效拍摄时间；撤销标签会重新计算其他证据，全部撤销后恢复导入表基线。

Excel 导出保留原表行号/排序、公式和原生图片，仅更新状态与时间列；置顶是页面视图行为。时间以完整 ISO 8601 文本保存，保留子秒和时区，避免 Excel 自动转换后丢失这些证据。相机未提供时区则保持原相机时间，不擅自补时区。已有状态列右侧被其他内容占用时会拒绝覆盖并提示先插入空列。旧任务自动升级，无需重导入，详细验收见 [016-拍摄进度标签页与完成时间](开发任务/016-拍摄进度标签页与完成时间.md)。

## 折叠布局与现场监控浏览

顶部「视图」菜单可折叠顶部、左右栏、选片工具；“专注预览”一次收起外围区域，再点击恢复。侧栏各功能及拍摄进度的任务/统计可分别折叠，拍摄进度的款号清单始终显示。布局按普通选片和监控拍摄分别保存在本机。

进入正在监控的照片目录后，左栏显示实时缩略图，中间使用大预览，选片工具默认收起；普通选片也在左栏显示照片缩略图，底部胶片条已移除。新文件写完并稳定入库后自动跟随；点击缩略图可回看，↑/←上一张、↓/→下一张。左侧“跟随新图”可暂停或恢复，暂停期间继续入库。监控缩略图、前后按钮、方向键及遥控滚轮统一遵循底部排序；可按拍摄时间升序、降序或星级从高到低浏览，缺少拍摄时间的照片排在末尾，刷新后保留排序选择。右侧星级和鼠标遥控始终对应当前定位照片，原有照片星级不会被新图覆盖。

照片稳定入库后，后台自动建立 480px 缩略图与最高 2048px 单张预览；普通导入、现场监控以及已有目录首次打开均会准备缓存。当前缓存根目录下 `previews/index.sqlite3` 记录文件指纹、尺寸、方向、访问时间及待生成队列，重启继续未完成任务，已生成的预览直接复用；相邻照片还会提前加载，减少来回浏览等待。预览图片总容量默认 10 GB，可在设置中调整至 1–256 GB，达到上限后优先淘汰最久未使用的可信缓存；原片、评级和资料库保留。首次生成、缓存被淘汰或原文件变化后仍需重新生成。不自动展开 RAW 像素。左侧照片滚动条始终显示并跟随主题色，可拖拽、点击轨道，聚焦后可使用方向键、PageUp/PageDown、Home/End。

大目录浏览采用数据库轻量索引，不把所有照片 JSON 一次塞进网页。超过 2000 张时，照片区显示页码和当前范围，可搜索整个目录、按时间/星级排序并跳页；单图前后导航会跨页。跨页评级使用局部变更保存，不覆盖未加载页；撤销也保留原有星级和 SKU 标记。当前页照片与覆盖映射有上限，网格/列表只生成可见行及缓冲区；组尾对比读取真实组尾两张，不将当前页末尾当成组尾。只保存光标/视图等偏好不再启动 RAW 全会话重扫，单张评级关联任务只处理相关记录并可重启恢复。初次导入、整目录导出和完整归档校验仍有各自的批量工作。

默认使用与 Lightroom 嵌入/附属预览相同思路的极速 JPEG：优先提取相机内嵌 JPEG，尺寸合适时保留原压缩码流，只整理元数据和方向；超限时快速缩到长边 2048px。新预览不再编码 WebP，也不运行高成本的 JPEG optimize。归档 420px、现场 480px 缩略图和 2048px 清晰图由每张一次读取完成，不再等全库小图结束才补清晰图；NAS 不额外限流，按 CPU/内存自动并发全速处理；自动后台任务不为内容去重完整读取原图。手工准备迁移指纹、备份导入的跨盘内容匹配继续保留。首次升级仅清理已登记且通过哈希归属核对的旧生成预览，照片、评级、SKU、业务索引、配置和未知/外部改写文件保留；旧任务转为新策略。方向用最小 EXIF 标记交给浏览器，原图不变。不默认展开 RAW 像素。缓存备份仍兼容旧 JPEG/WebP，局域网和 OCR 使用 JPEG。

预览会读取 JPEG/RAW 的旋转及镜像方向；明确的 JPEG 内嵌方向优先，缺失时使用入库方向信息，只处理预览，不旋转改写原片。右键左侧缩略图、网格或大图，可在资源管理器打开目录并选中原文件，RAW+JPG 配对另提供选中 RAW。右键菜单打开时暂停遥控计星，避免误触。完整说明与验证见 [017-LR折叠布局与实时监控选片](开发任务/017-LR折叠布局与实时监控选片.md)。

缓存清理只处理已登记生成参数、缓存键及内容校验值均匹配的软件预览，不再接管任意哈希命名的 JPG，也不扫描删除来历不明的临时文件。同名文件归属不明或已被外部替换时保留文件并报告预览生成失败；不会为腾出缓存空间删除或覆盖它。详见 [073-监控目录原图保护与历史接续](开发任务/073-监控目录原图保护与历史接续.md)。

## 统一界面动效

页面切换、配置编辑、应用内右键菜单、弹窗开合、顶部/侧栏、详情折叠使用统一贝塞尔缓动 `cubic-bezier(.22,1,.36,1)`，按交互分为120/200/240ms。动画只处理界面外观，切换、评级与弹窗关闭的业务状态立即生效；新照片入库不逐张播放入场动画。系统启用“减少动态效果”时自动关闭动效。原生系统文件对话框和系统下拉列表仍由Windows绘制。


## 真实照片可操作演示

双击根目录 `启动真实数据演示.cmd`，打开本机演示页 `http://127.0.0.1:18770`。使用指定实拍目录中的 10 组照片副本，按按钮逐步执行“随机标星（含 1 星/2 星组）→ 随机演示 SKU / 款图备案 → 最终 JPG/RAW 写入 → 独立读取核验”；可打开同一正式引擎的工作台查看每一步实际数据。

演示星级和带“演示SKU”前缀的款号明确属于随机演示值，照片/EXIF 真实，字段实际写入本地副本。原始基准、每轮副本、独立数据库和报告位于 `build/真实数据可操作演示/`，不替换生产库或修改 X 盘原件。可开始新一轮，旧轮次保留。入口使用本机 Python 与已构建的发行引擎，不是独立便携安装包。

元数据任务表按照片显示：同一张照片的 JPG/RAW 合并为一行，格式显示 `JPG/RAW`，目标提示可查看两个实际路径；进度和最终核验仍按实际文件计数，单组件失败会单独说明。


## 开发版局域网团队工作台

桌面版“资产检索”与 Web 检索采用相同的紧凑布局：顶部拍摄进度／资产检索／资产归档导航，搜索框右侧排列归档位置、素材类型和搜索方式，左侧固定参考图，主区域显示结果。桌面选中资产后展开可关闭的详情面板，继续支持预览、打开目录、人工 SKU 和解析操作。右上角齿轮提供快捷搜索、多维解析、检索设置、Web 共享及其他工作台入口；切换到其他桌面页面时恢复原底部导航。独立快捷搜索窗口保留三栏布局。

程序提供“拍摄进度、资产检索、资产归档”三个 Web 标签页，与桌面端共用数据库。在桌面“资产检索 → 右上角齿轮 → Web 共享”或“设置 → 文件与备案”开启，复制局域网地址（默认端口 8780）给同事。正式版仍需访问码；通过 `启动多模态检索开发版.cmd` 启动的开发环境免码。浏览器只读查阅并自动刷新，支持电脑、平板及手机；工作站与软件需保持运行。共享默认关闭，不影响本机管理端或原参考库共享。

重新编译请运行 `python 选片助手/build_release.py --stage-only`，完整发行目录为 `build/tauri-release/末帧选片`。仅执行 Cargo 不会更新冻结 Python 引擎中附带的页面；构建会核对工作台资源与当前源码，发现旧资源时拒绝交付。

详细使用、同步逻辑与访问边界见 [多模态检索架构的局域网工作台说明](技术文档/多模态SKU资产检索架构.md)。
