# Lightroom Classic 连拍末张标星

这个插件只修改 Lightroom Classic 目录中的星级，不写入、移动、重命名或删除原图。

## 规则

- RAW 和 JPG 文件名主体相同时，视为同一个拍摄编号并同步标记。
- 先分析当前选择中的所有相邻间隔，在对数尺度上自动识别「快速连拍」和「换动作/换款」两种节奏。
- 以两种节奏中心的几何中点作为分界，不再固定写死 3 秒。
- 与下一个拍摄编号间隔不超过自动阈值时，当前张视为连拍前帧。
- 每组连拍只给最后一张标 1 星。
- 间隔大于自动阈值时，视为新角度或新款，单独保留并标 1 星。
- 已有 2–5 星的照片不会被降级。非保留张只会清除 1 星。

## 使用

1. 在 Lightroom Classic 的「图库」模块打开目标文件夹。
2. 按 `Ctrl+A` 全选该文件夹照片。
3. 先运行「图库 > 增效工具额外选项 > 预览当前选择（自动识别连拍间隔）」。
4. 核对快/慢节奏中心、自动阈值和预计保留数量后，运行「执行：连拍只标最后一张（自动阈值）」。
5. 用 Lightroom 的「星级 >= 1」过滤器只看候选片。

一次执行在 Lightroom 历史中是单个目录写入操作，如需撤销，执行完后立即按 `Ctrl+Z`。
