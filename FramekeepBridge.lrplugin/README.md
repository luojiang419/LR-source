# Lightroom 末帧选片桥接

在 Lightroom Classic 增效工具管理器加载此目录。菜单位于「图库 → 增效工具额外选项」。

- **连接末帧工作台（自动重连）**：轮询本机 `127.0.0.1:8769`，同步前显示预览，确认后写入星级并回传。
- **导入末帧选片清单**：读取正式 v2 `.framekeep.json`；拒绝演示清单，不执行文件中的代码。
- **撤销上次末帧同步**：恢复当前插件会话中最后一批同步；同步后被人工改过的评级不覆盖。
- **断开末帧工作台**：停止后台重连任务。

照片需已导入 LR。读取目录元数据和写星不依赖全部 RAW 缩略图就绪。已有 2–5 星保护；相对路径越界、重复路径和无效星级被拒绝。未匹配和未列入清单的照片不改动。RAW/JPG 若只存在一个 LR 主记录则仅修改主记录，并报告未独立匹配的配对项。

匹配优先原路径和已配置磁盘别名；为零时读取 LR 的路径索引，查找同名源目录的唯一对应项；多个副本需手动映射。查找不等于文件内容校验，确认前请核对源目录、匹配数量和星级变更。

升级后必须在增效工具管理器重新载入插件，关闭旧同步对话框后再接收新任务。
