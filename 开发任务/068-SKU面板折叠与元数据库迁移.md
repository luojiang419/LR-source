## 验收范围

- SKU 数据库左侧组和款号面板可分别折叠、恢复，支持键盘操作，刷新保持；四主题与窄屏兼容。
- 设置新增“数据库管理”，提供“导入元数据／导出元数据”。导出全部 SKU 关联库、OCR、分组、区间、照片索引及拍摄文档，不受页面筛选和分页影响，不包含原照片、模型密钥及机器自动运行设置。
- 采用带格式版本和完整性摘要的 JSON 文件；新机器可导入并搜索、浏览和继续导出，原路径离线时仍保留元数据。照片需另外迁移。
- 导入合并独立数据，不覆盖既有记录；冲突、损坏和不兼容文件明确报错且回滚。重复导入同一备份不重复添加。迁入的自动识别／写图任务暂停，不自动操作原照片。
- 隔离数据库执行迁移、重复导入、冲突回滚、损坏拒绝、重新启动、OCR 搜索与浏览器操作验证；构建更新本机程序，保持正式版本。
- 后续用户要求：新机器先导入资产归档，再到设置导入 SKU 数据库即可自动关联新路径照片，恢复 SKU、类型、项目／区间、星级和 OCR 资料，并完成照片内嵌元数据同步。沿用永久资产身份／文件校验／可靠拍摄身份匹配，不凭同名误配；冲突、缺图和歧义明确报告。新流程用户已授权实际同步归档文件，不再要求旧机器路径一致。

## 实现

- `sku_metadata_backup.py`：固定表清单导出三个关联库的元数据，连同源拍摄文档／对账副本，形成 `framekeep.sku-metadata` v1 JSON 备份；SHA-256 校验、200 MB 上限，排除原照片、密钥及机器自动运行设置。导入使用本机表结构白名单，不执行来源 SQL；关联库事务合并，冲突及文档落盘失败回滚，已有不同记录不覆盖，同一摘要只导入一次。
- 迁入项目自动识别关闭，未完成 OCR 取消、未完成写图转为可人工重试的失败状态、拍摄段暂停、旧事件标记已交付；不会因导入或重启直接重放原机器操作。保留已完成历史、共享星级、文件身份、拍摄区间、完整 OCR 和虚拟分组。原机器的写图恢复副本另行备份，不包含在本次元数据文件中。
- `server.py`：令牌保护的导入／导出接口及匹配大小上限；`asset-metadata.js`：新增数据库管理分类、文件选择、进度／错误／重复导入反馈，完成后刷新资料；桌面 `save_manifest` 兼容元数据原生另存为，浏览器使用下载。
- `sku-media-pool.js/.css`：组与款号面板可独立折叠，始终可见的顶部按钮支持键盘及 `aria-expanded`，本机保存状态；四主题和窄屏下隐藏面板释放布局空间。
- `sku_library.py`／`asset-library.js`：保留离线归档记录，对当前显示页标记离线并显示提示；不随原图暂不可用而丢失 SKU。修复旧列表快照未包含搜索词的问题：搜索命中全部数据时也正确切换搜索标题及图片区。
- README 增加备份／迁移操作和照片路径要求；既有设置测试同步新增分类及末项定位。
