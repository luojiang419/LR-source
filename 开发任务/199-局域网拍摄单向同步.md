## 范围与验收

- 设置开关、本机名称、任意文本同步密码、小档根目录；发现页双击或右键联机并输入同步码。
- 单独局域网监听与 UDP 发现，不暴露桌面管理接口；接收端不上传、不接管现场拍摄。
- 原始 JPG 小档与已有／后续新增 XMP 按来源机器／拍摄日期落盘，同名不同来源隔离，传输校验和原子替换；RAW 原片不属于小档传输。
- 拍摄文档、进度、SKU、OCR 和资产归属入本地业务库，ID 按来源隔离；不复制活动 SQLite 文件，不执行远端 SQL。
- 退出后文件和进度保留，选片目录可回看，SKU 资料用于本地最终大档归档；断线重试和重启恢复，重复接收不重复入库。
- 用两个独立数据目录与真实 HTTP 连接验证错误密码、首次／增量同步、评级及 XMP 更新、离线留存、路径边界和实际页面。

## 已实现行为

- 设置 → 局域网同步仅提供开关、名称、密码、小档目录、保存、发现及退出。密码支持数字、大小写、中英文、空格和符号；留空保存保留旧密码。接收状态显示来源和拍摄／待机状态。
- 发现采用 UDP 48781 组播＋广播、多网卡探测；双击、右键「联机」及 Enter 打开同步码弹窗。独立 TCP 同步监听器只提供挑战、鉴权、修订、清单和内容摘要文件下载；不开放桌面管理接口。
- 使用 PBKDF2 派生密钥、一次性挑战、双方 HMAC 校验、限次验证及短期会话令牌；不在网络发现、状态接口、日志或业务快照中返回密码／密钥。局域网传输为 HTTP，不提供 TLS。
- 默认每秒检查来源修订；未变化时不传整份清单。接收原始小档字节、XMP 和工作簿，逐文件 SHA-256 校验、临时文件原子替换，已完成文件可复用。源库变化时发送固定表业务快照，本地按记录散列及实际内容增量投影；不是逐事件日志协议。
- 目录形如 `小档根/现场 A [设备ID前8位]/2026-11-09/拍摄-会话摘要/原相对目录/原文件名.JPG`。日期取照片拍摄日期，缺失为「日期待确认」。拍摄会话来源包含拍摄绑定、现场证据和当前选片；NAS／归档会话不传原片。只有 RAW 而无配对小档的拍摄记录明确停止并报错，不伪造成功。
- 会话、拍摄文档、行与作业 ID 按设备映射；永久 AssetId／FileId 保留原图 XMP 身份，遇本机其他来源同身份冲突时停止。保留二星／评级、SKU、OCR 可检索原文、重拍母款关系、元数据指纹版本链、拍摄完成证据、区间和双图引用。
- 业务库先提交、散列与收据随后登记，崩溃可幂等重放；待发布快照持久化，文件齐全时离线重启也可完成入库。退出中止剩余传输；不删除文件、照片索引或业务记录。
- 接收前停用 Canon 和目录监控；本机写接口在引擎侧拦截，浏览、目录切换和历史查看可用。收到的待执行识别作业转为取消，拍摄项目禁用、区间关闭，不在接收端执行来源队列。不自动恢复现场拍摄。
- 持久来源标记独立保存，退出后保存视图也不会失去来源；接收资料不再次广播，不通过选片切换触发自动解析或 RAW 写入。
