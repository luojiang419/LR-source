## 目标与方案

- “文件数据库与 API”提供 Everything 调用开关，默认沿用启用策略；关闭后立即阻止 SDK 调用，自动补建本机索引，设置重启保留。
- 文件索引数据库可选择独立目录并迁移到 SSD；移动的是本软件参考文件的 SQLite 数据与倒排索引，Everything 自己的数据库仍由 Everything 管理。已有预览缓存迁移保持独立。
- 迁移协调读写、暂停扫描，SQLite backup 包括 WAL 中已提交数据，完整性校验后原子保存新位置，原库保留。失败继续使用原位置，新位置离线明确报错，不静默切到旧快照。
- 不移动原图、API 密钥或业务资料，不覆写非空目标。校验范围包括调用开关、索引命中、并发写入、失败不切换、重启恢复与真实设置页面。
- 必要源文件备份 `backup/v010/`；不包含数据库、依赖和用户文件。

## 实现记录

- `everything_search.py` 将用户开关保存在资料目录 `everything-settings.json`，串行等待当前有界 SDK 请求后切换，关闭后不再启动 SDK worker；测试环境禁用项仍优先。`reference_api.py` 新增本机管理路由，关闭时自动补建缺少完整快照的位置。
- `reference_storage.py` 读写门允许平时的扫描和查询并行；迁移时暂停扫描、等待已开始的操作、关闭后台倒排构建及 WAL 生命周期连接，SQLite backup 包含 WAL 已提交数据。逐库 quick_check、记录数校验后，以原子配置写入切换目录。
- 目标必须为空，拒绝资料、具体照片目录、当前索引目录、链接目录及重叠位置；整盘已添加时允许独立子目录并自动排除索引位置。所选空目录内独占创建随机名称子目录，不覆盖并发新出现的文件。
- 原位置及失败副本保留，不提供自动删除数据库功能。重启按标记身份验证外部位置；离线/身份不符明确报错，不创建空库或退回旧快照。迁移作业计入升级/退出忙碌检查。
- 设置界面提供持久开关、路径显示、目录选择、迁移百分比、错误与原位置提示。未将本机索引路径迁移扩展为全资料移动，已有 SKU / OCR 业务资料、密钥、预览缓存及 Everything 自己的库路径保持原管理方式。
