## 实现

- `sku_service.py`／`server.py`：导入请求可携带期望工作表，在创建项目时一次选中同名或首个有效工作表，可同时绑定指定目录；允许无目录时切换工作表查看，实际 OCR 继续要求有效照片目录。旧 API 不传新字段时保持原行为。
- `sku-reconciliation.js`：导入成功清除旧搜索／状态筛选，延长大表格请求超时至 90 秒；不再分两次请求创建项目和绑定，导入期间冻结目标目录。无目录不误显示“已绑定”，不产生有效 OCR 上下文；显式绑定仍提示先打开目录。沿用 mutation 防护，旧轮询回包不覆盖新项目。
- `folder-watch.js`：移除检测到 EOS 运行后自动打开保存目录的分支；显式入口、等待 EOS 退出应用设置、Canon 自动通知和监控继续保留。
- `workbench-layout.js`／`toolbar-layout.css`：移动原星级 DOM 到预览左下角，复用原点击事件、快捷键与自动保存；窄窗口将星级上移避免覆盖右下角缩放控件，空照片不显示空框。
- 更新 README 和 Canon 接入文档；沿用已有测试并修正旧测试中“必须有文档才能开启 OCR”和“状态仍为最后一列”的过期断言。
