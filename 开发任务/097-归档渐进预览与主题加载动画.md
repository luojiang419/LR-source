## 方案与验收

- 双击立即复用当前已显示的 420 缩略图；无缓存时先请求小图，与大图并行，任何时序均不得由小图覆盖已完成的大图。
- 大图在浏览器完成解码后覆盖缩略图，短暂淡入，保持缩放与平移；快速切图和关闭时取消旧请求并防止旧响应串图。
- 没有小图时展示主题色 SVG 和明确的准备预览文案；已有小图时使用底部轻提示，失败保留小图并提示，禁止伪造百分比。
- 网格先展示素材及 SVG 占位，仅加载视口附近缩略图，最多 3 个并发；打开大图暂停网格请求，关闭后恢复，避免首次归档大量图片挤占浏览请求。
- 深色、浅色、纯白、硬核主题使用主题变量；减少动画设置停用旋转和淡入。验证使用隔离照片及可控延迟，不操作用户运行窗口或原照片。

## 交付与验证

- `asset-loading.js` 提供共享的主题 SVG 和可见区加载队列；`asset-library.js` 在归档与 SKU 网格使用相同占位和最多 3 个并发请求。打开大图暂停并取消网格未完成请求，关闭后继续加载。
- `asset-viewer.js` 直接复制已解码缩略图的像素，禁用 HTTP 缓存时也可立即预览；未就绪时高优先级请求 420 小图和 4096 大图。大图经 `decode()` 后用 180 ms 淡入覆盖，保留缩放与平移；关闭及切图清理请求、事件和替换计时器，旧响应不能影响当前图片。
- `asset-workspace.css` 使用主题文本、背景和边框变量，加载画面在浅色／纯白主题保持可读；失败停止动画、保留已有小图，并提供文件离线提示。系统减少动画时停用动画。
- 执行：`python -m unittest test_asset_viewer test_asset_catalog_browser test_archive_locations_browser test_progressive_archive_browser`，5 项通过。既有测试验证真实预览解码、资料读取、缩放拖拽、原片未变和归档／SKU 页面；新增测试以 48 张隔离图片及受控响应验证冷启动 3 请求上限、双向到达顺序、加载失败、切图和关闭后旧响应、网格恢复及已显示小图无重复请求。
