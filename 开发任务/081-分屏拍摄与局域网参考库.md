## 后端与设置

- `reference_library.py`：后台流式持久扫描，复用 AssetCatalog 的 RAW/JPG 合并和统一预览缓存；独立根数据库支持重叠目录。打开目录时补齐当前层；Everything 可用时按目录与字面搜索组合加速，失效时使用目录索引。整盘扫描不限演示阶段的 20,000 张。
- 正常关闭中断索引后保存 queued，重启续扫；移除资源位置只撤销索引入口与对应授权，不删除原文件；内部资料与迁移后的缓存目录不被共享。
- `reference_api.py`：独立 LAN 服务默认关闭，默认端口 8770，只开放四类 Bearer 鉴权读取接口，不开放选片、管理、写入接口；本机管理继续使用原 Host／Origin／CSRF 校验。
- Key 支持命名创建、目录分配／重新分配、查看、复制和停用；Key 与对端凭据采用当前 Windows 用户 DPAPI 加密持久化。客户端输入 IP:端口后自动补齐协议及接口路径，通过本机代理读取对端；远端不返回绝对路径或盘符。
- 前端主要文件：`split-capture.js/css`，并对 `index.html`、视图菜单、设置分类、评级提示做小范围接入；`build_release.py` 增加正式打包资产。使用说明见 README 新专节。
