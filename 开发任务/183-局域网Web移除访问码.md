## 目标和验收

- 所有运行方式的 Web 工作台均直接进入，不生成、校验或轮换访问码，不签发登录 Cookie。
- 删除登录页、退出登录和共享设置中的访问码操作。连接失败显示读取错误并重试。
- 旧配置中的访问码不影响共享开关、端口和启动，下一次保存只保留共享开关与端口。
- 保留局域网/Host/同源边界、Web 查阅与图搜接口范围、本机桌面管理令牌、参考库 API Key。
- HTTP 与真实浏览器验证首次访问、刷新、检索、图片及重启免码，正式冻结引擎验证后部署本机。普通调试不递增正式版本，不发布公网更新。

## 实现及验证

- `lan_workspace.py` 删除访问码生成、校验、会话和 Cookie 逻辑，登录/退出接口返回 405；读取旧配置时仅保留有效的 enabled/port，旧访问码格式损坏也不影响共享启动，下次保存移除废弃字段。
- `server.py` 与开发启动器统一使用免码工作台。公开状态 `login_required=false` 和管理状态 `access_code_required=false` 保留作旧前端兼容，不提供访问码。
- Web 删除登录表单与退出入口；连接失败显示实际错误，自动重试。桌面共享设置只提供开关、端口和地址复制。
- HTTP/浏览器回归覆盖无 Cookie 查阅、图搜、刷新、旧配置迁移与重启、首次连接失败后自动恢复、只读/Host/Origin/客户端地址边界、本机管理令牌。
- 证据：`build/lan-no-code-regression.log`、`build/lan-no-code-build.log`、`build/lan-no-code/frozen.json` 和 `frozen.log`。
- Windows 控制工具可读取原生文字树，但窗口捕获两次超时，组合框设置未生效；原 `desktop-preferences.json` 字节核对不变。改用当前安装引擎已有的桌面鉴权关闭接口，等待引擎退出后才结束空桌面外壳，没有强制终止引擎或替换活动程序。
