## 实现与边界

- `桌面程序/src/desktop_preferences.rs` 在资料目录保存 `desktop-preferences.json`；枚举校验、默认询问、原子替换，启动项写入失败不把界面误报为保存成功。Windows 当前用户 Run 值 `Framekeep` 使用带引号的真实程序与资料目录，`--startup --silent` 静默启动；系统移除启动项后重启会显示实际未启动状态。
- `main.rs` 创建原生托盘，单击恢复、菜单打开和显式退出；启动窗口 `.visible(!silent)`；重复自动启动与 Canon 照片通知保持后台，普通重复启动恢复现有窗口。隐藏也先保存评级；退出沿用后台任务确认与引擎关闭；自动更新的退出路径继续直接退出。
- `desktop.js` 共用原生启动页与工作台的关闭交互，提供开关、取消、Esc 与失败重试。工作台就绪上报明确检查 `127.0.0.1`，避免 Windows 的 `http://tauri.localhost` 启动页提前上报。
- 设置新增“启动与关闭”，设置自动保存，浏览器模式禁用原生选项并解释需使用桌面版；沿用现有设置导航、主题和窄屏布局。卸载仅删除指向自身目录的启动项，不动其他安装或其他程序。
