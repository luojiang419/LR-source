## 目标与验收

- 任意主机均允许HTTP/HTTPS，不再限制HTTP仅本机。
- 支持IP+端口、域名+端口、域名及完整地址；自动补齐协议，探测模型路径，返回并显示成功地址。
- 明确填写的协议保持；无协议地址按主机/端口选择首选协议，连接失败时测试另一协议；鉴权失败明确提示。
- 模型列表路径与保存后SKU/资产解析请求使用同一基址，支持自定义路径及完整Chat/Responses/Models地址。
- 编辑时自动获取列表，保留手动刷新、模型选择、手填和保存选用；迟到请求不覆盖新草稿，密钥不进入错误或返回数据。
- 隔离HTTP模拟服务、真实Chrome及打包引擎验证；不向真实付费服务发送图片或修改生产配置。

- 新增 `api_endpoints.py`：共用HTTP/HTTPS地址校验、简写补全、基址与实际请求地址拼接。IP/localhost/非443显式端口先HTTP，普通域名/443先HTTPS；明确填写协议时保持，仅简写地址探测另一协议。支持IPv6方括号与IDNA域名。
