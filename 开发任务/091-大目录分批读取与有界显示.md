## 目标与验收

- 超过 2000 张的现场目录自动按有界批次读取（每批最多 240 张）；小目录既有行为兼容。搜索、目录筛选、排序、总数与已选计数覆盖全目录，不能把首批误报为全部。
- 初始脚本和状态响应不序列化全目录照片；当前批次明确显示范围并可前后跳转，单图跨边界导航和监控跟随可定位到对应批次。
- 分批保存只提交本批变更，不覆盖其他批次的评级、SKU 标记及原有状态；保留 revision 冲突保护、人工评级和原图安全。
- 浏览通过持久轻量 SQL 索引，完整照片 JSON 仅对本批读取；分组边界在批次之外仍正确，不能重新把每批结尾当末帧推荐。
- 网格和列表仅绘制可见行及缓冲区；不因切图或标星重建全目录节点。后台队列和预热按批工作，不在首屏等待全部大预览。
- 使用隔离资料验证十万记录首屏/搜索/排序/末批、跨批保存/重启、真实图片网格和单图、原片哈希、DOM 数量与页面错误。性能数据注明合成记录/真实文件范围，不宣称百万真实照片端到端支持。

## 实现记录

- `session_browser.py`：原始照片 JSON 外建立轻量索引，按批解码最多 240 条；全目录分组、搜索、排序、总数与已选计数。组尾对比只读取真实组尾两张，不把当前页末尾当组尾。时间索引区分本地无时区和明确时区，保持与原 JS/Python 排序一致。
- 分组缓存只在时间/相机/顺序变化时更新；共享评级缓存由原生 SQL 版本触发器失效，兼容同资产位置和跨会话关联。计数缓存有上限，页内偏好变化不反复扫描评级。
- `/assets/demo-data.js` 和 `/api/state` 大目录响应有界；空查询参数保留，清空搜索/目录不会被旧会话条件替代。旧的小目录 API 行为保持，显式批量导出继续覆盖整个会话。
- `session-paging.js` 提供范围、前后页、跳页和跨页单图导航；网格/列表只渲染可见行及缓冲，缓存前端模型、位置映射及实际行高。侧栏已有虚拟节点继续使用，图片比例记忆有上限。
- 局部保存采用差异 patch，保留其他页的评级和 SKU 标记；版本检查、保存与评级/SKU 回调保持同序。加载前冻结操作并等待保存，切目录/联机刷新等待正在进行的分页；跨页撤销保留有效旧星级，删除未加载 SKU 标记时显式发送空值。
- 前端只保留本页的评级/标记覆盖映射，旧本地恢复记录也按本页裁剪；全目录评级保存在数据库，不能通过无限合并已访问页的覆盖映射变相全量驻留。
- 目录树只聚合路径索引；文件列表查询最多 200 条；侧栏 SKU 仅查询当前页，避免后台 2 秒轮询重新展开全目录区间。
- 新增照片只查询涉及路径，目录快照流式哈希；共享评级索引按批构建并原子发布，只读偏好修订不重建。点选资产/照片、归档状态文件名查询均使用 ID 范围。
- 保存纯界面偏好不再触发 RAW 会话重扫；单张评级变化持久保存 capture_ids，仅更新相关来源与已关联 RAW。局部任务可合并/重启恢复，全量发现任务优先，不缩小既有导入/发现范围；整目录来源重建改为分批读取。归档显式完整校验仍保持原保护流程，不为性能降低原图校验要求。
- 两处历史 RAW 测试直接读取内嵌字段，与已上线 XMP 侧车契约不符，改为 `read_asset` 读回；真实 RAW 全文件/像素保护测试保持。
