## 目标与验收

- 输入、修改及清空关键词后自动查询；连续输入 300 ms 后提交，中文输入法组合期间不查询，点击搜索或回车立即提交。
- 新输入使旧请求失效，旧结果不能覆盖新查询；自动搜索重置分页，翻页沿用当前关键词和范围。
- 固定参考图、临时加载图片、选中位置和面板状态不因会话或拍摄文档切换自动清空；手动移除和清理继续生效。
- 本机与 API 目录均通过真实浏览器验证；重载恢复持久参考，任务切换后离线 API 缓存仍能复用，原照片不变。
