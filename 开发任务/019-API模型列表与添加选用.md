## 目标与验收

- 新增和编辑配置时，根据当前接口地址/协议/密钥获取可用模型；已有卡片留空密钥时使用原密钥，密钥不回传页面。
- 显示可搜索的模型列表，选择后填入模型ID；未提供列表接口的服务允许手填，错误不清空当前配置。
- 支持保存卡片以及保存并选用；多个同类模型分别保留卡片，类别之间独立，资产视觉专用绑定继续保持独立。
- 获取列表不发送图片、不产生模型推理、不自动保存或改选模型；过期请求不覆盖新编辑内容。
- 保留原有监控、评级、数据库与配置；浏览器与最终包分别验证，真实上游未验证时明确记录。
